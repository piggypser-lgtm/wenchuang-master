# 按阶段与问题查阅的建模、配件与打印参考库

本库保存公开来源索引、原创摘要及使用规则，不包含第三方文档全文、模型或个人案例。来源索引维护日期：2026-11-08；使用时核对当前原文和适用版本，不把整理日期视为所有链接永久有效的保证。

## 查阅方式

在当前阶段遇到影响方案、尺寸、结构或打印结果的问题时，按下表选择最相关来源，通过 [设计参数查证](parameter-research.md) 中的 Web Access 方法读取对应章节。无需每次遍历所有网站；已有资料的型号、版本及条件仍适用时直接沿用。关键功能参数仍须在定稿和正式绘图前查证，不能用本索引代替原文核实。

查询后简要说明“遇到的问题 → 原文适用结论 → 本项目采用或不采用的理由 → 尚需验证的部分”。一般查阅属于当前任务内部工作；新增硬件、改变外观或功能时先提供选项并更新受影响设计，仍须遵守阶段验收，不提前建模、安装、购买或启动设备。

## 成熟机构优先入口

机械／活动结构在用途方案阶段先筛选 [机构卡片](mechanism-library.md)，按 [复用与验证规则](mechanism-reuse.md) 比较源码、许可、实物证据和适配代价；卡片保存具体候选，文创／玩具的旋转、齿轮、连杆、搭扣和叶簧见 [互动机构](toy-mechanisms.md)，证据未齐的方向见[待查记录](mechanism-candidates.md)；以下 R 编号仍是按问题查资料的入口。卡片中的作者记录不等于本项目已通过，普通库函数和平台模型总数不计入有实物记录的机构数量。

## 阶段与问题路由

| 阶段／触发问题 | 优先查阅 | 本阶段应得到的结果 |
|---|---|---|
| 可行性：细长部位、活动连接、悬垂或打印方向可能影响实现 | R1 伯克利、R2 Prusa；特定机构补 R3 | 风险、可行改法及待试样验证项，不先承诺能打印 |
| 品类与用途共创：需要更多功能方向，或希望模型能转动、开合 | 既有 [文创品类库](product-library.md)；需当前案例时 R18 MakerWorld；R9 机构示意；需要实体配件时 R4 | 有用途和取舍的候选；不因找到配件而自动扩大功能范围 |
| 品类／用途共创及后续参数：桌搭、充电承托、小设备收纳、桌边／桌下安装 | R15 桌面数码参考；尺寸阶段查对应设备／组件制造商资料 | 设备组合、安装方式、候选取舍及待核实尺寸；区分承托成品设备与新增电子功能 |
| 用途／参数方案：齿轮齿条、机械拼装、标准锁紧件或轴系缺少合适来源 | R17 STEMFIE；先比较既有机构卡 | 具体零件身份、可用设计源、许可、兼容接口及新增件数，不把零件库当整机验证 |
| 共创及参数：成品灯具、灯箱、主题灯罩 | L 类与 [灯光参数](products.md#成品灯具与灯光文创)；R4 发现组件，具体尺寸／安装条件查制造商 | 明确所用成品灯光组件和打印外壳职责，不自动引入自制电路或 CyberBrick |
| 用途共创：用户希望电动、遥控或可编程交互 | 可选 R10 CyberBrick，电子外壳案例可补 R6 | 是否采用电子扩展、预算和体积影响；不默认购买或安装 |
| 参数定稿、主视图及参数图：磁铁、轴承、螺钉、模块、插口等真实接口 | 对应制造商型号资料；R4 Maker’s Supply、R5 McMaster-Carr、R6；选用 CyberBrick 才查 R10 | 型号、尺寸与基准、安装和走线空间，登记硬件清单及来源 |
| 结构方案和功能草模：卡扣、榫卯、滑动配合、铰链、分件装配或原位打印 | R1、R2；卡扣重点 R3 | 连接原理、配合与装入方式、受力方向、需验证的试样；不照搬通用间隙 |
| 材料选择或试样失败：弹片易断、连接松动、反复使用磨损 | R2 材料指南、实际耗材厂家资料、R3 相关结构章节 | 区分材料、方向、结构及尺寸原因，形成当前问题的修改或试样方案 |
| Blender 建模、细化与导出：破面、相交、薄壁、异常凸起、保护区差异或导出核验 | R7 Blender、3D Print Toolbox、Trimesh；按 [工具规则](modeling-tools.md) 选择 | 读取实际报告，区分原件与诊断副本及采样限制；定位缺陷并保护功能结构，不以自动修复代替复查 |
| Blender 代码建模：重复的拉伸、孔槽、布尔、倒角或部件定位 | 可选 R16 Sand3D 函数库 | 核实函数、宿主兼容性与单位，测量实际网格；不引入模型数据集 |
| 建模分工与功能草模：精密接口、CAD 实体或频繁按尺寸重建 | 可选 R14 CadQuery；默认仍评估 Blender 代码 | 选定构件范围、参数源、单位与离散误差，生成后回 Blender 整合验收 |
| 代码建模时需控制多个截面与连续圆角 | [SMLib 适用条件与官方资料](modeling-tools.md#smlib-多截面曲面) | 按已确认图纸建立放样部件，回到 Blender 检查端部与接缝 |
| 打印方案：当前预设来源、继承或工程覆盖不明 | R8 官方配置目录及本机实际工程；具体耗材／板材厂家 | 核实生效基准和未知项，不用仓库最新版覆盖本机 |
| 程序化准备／切片：希望批量配置，或接口与工程格式兼容性不明 | R8 CLI、对应版本源码与本机能力 | 按 [代码配置与切片](slicing-automation.md) 分开验证工程准备、界面载入与切片，保留既有验收 |
| 摆盘与配置、切片：朝向、支撑、薄壁消失、材料／板温或软件操作不明 | R8 Bambu 官方资料；R1、R2 补通用原理；实际耗材／板材厂家 | 按 [参数决策](slicing-parameters.md) 展示修改依据，配置验收后切片并检查结果 |
| 实物反馈：开裂、配合失效、层阶或支撑难拆 | R8 设备排错、R2 材料／方向、R3 对应连接机制 | 把故障对应到可验证原因；仅重新核实受影响资料和参数 |
| 共创与参数设计：主体适合活动、需要可调功能零件或模板启发 | R11 MakerLab／BOSL2；分节玩具可选 R12 | 活动意愿、具体用途、可控参数、兼容性与许可；仅浏览资料和讨论方案 |
| 图纸与路线验收后：需要生成可复用机构或功能零件 | R11 及 [参数化执行规则](parametric-structures.md)；选定玩具路线才用 R12 | 参数化源、版本与参数、实际生成结果、Blender 整合检查和待试样验证项 |

## 解压与 EDC 路由

共创出现随身把玩、点击、磁吸滑动、旋转或翻折需求时，查 R13；参数阶段核实具体源码、配件与许可，图纸验收后的建模阶段才生成或改作零件，实物反馈阶段按回弹、噪声、阻力与磨耗回查。无需普通静态产品遍历该分支。

## 来源索引及使用边界

### R1 伯克利实验室：基础设计检查

[Lawrence Berkeley National Laboratory — 3D Printing Knowledge Base](https://3dprinting.lbl.gov/3d-printing-knowledge-base)

页面目前标注 BETA，涵盖零件接口、打印方向与层间强度、配合及公差试样、内部结构与原位打印、圆角倒角、悬垂与桥接。用于可行性和结构方案的基础检查，尤其是“选何种连接、如何受力、是否需要先试配”。

它不是特定产品机构的设计认证，也不是适用于所有 FDM 设备的统一标准。配合间隙须核对单边／总间隙定义；悬垂角度须核对测量基准。原文未明确材料、设备或定义时，不直接复制数值；条件不充分的概括也不能升级为绝对禁令，应结合实际结构与对应工艺查证。

### R2 Prusa：FDM 设计与材料

- [Modeling with 3D printing in mind](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)：支撑、朝向、分件及配合设计。

- [Material guide](https://help.prusa3d.com/category/material-guide_220)：按具体材料查用途、打印准备及局限。

用于绘图前的制造判断、功能草模的配合方案，以及材料和实物问题分析。区分通用 FDM 原理与 Prusa 设备的性能或预设；实际耗材和目标机器参数优先查对应厂家，不直接移植其他打印机的温度、精度或间隙。

### R3 Formlabs／Protolabs：卡扣与装配专题

- [Formlabs — How to Design and 3D Print Snap-Fit Joints](https://formlabs.com/blog/designing-3d-printed-snap-fit-enclosures/)

- [Protolabs Network — How do you design snap-fit joints for 3D printing?](https://www.hubs.com/knowledge-base/how-design-snap-fit-joints-3d-printing/)

需要可拆壳盖、扣合轴、防脱或弹性定位时，查连接形式、变形方式、根部过渡和材料限制。机构原理可供比较，但 FDM、SLA、SLS 及注塑条件下的尺寸、材料性能和工艺结论须分别判断；不能把资料里的示例当作当前材料的保持力或耐久验证。

### R4 Maker’s Supply：实体配件与安装依据

[官方配件库说明与入口](https://blog.bambulab.com/from-vision-to-reality-creating-without-limits-with-makers-supply/)

提供磁铁、轴承、紧固件和电子组件等非打印配件的尺寸、数字模型及部分组件指南。用于功能共创和型号确定后的参数设计。沿官方入口到当前地区的具体产品页，核对 SKU、规格图、CAD 与实际配件是否一致；有数字模型不表示可忽略实物差异和配合试样。

先确认用户接受加入非打印配件，再围绕它确定结构；仅参考资料不要求购买。项目记录所需零件及数量，不把特定地区库存、价格或作者已有配件写进公开 skill 默认值。

### R5 McMaster-Carr：工业零件 CAD 与图纸

[McMaster-Carr CAD Models](https://www.mcmaster.com/cad-models/)

用于查对应型号零件的二维图纸和三维占位，辅助检查螺钉、轴承等的空间与装配关系。核对公制／英制和型号，不能以相似外形替代手头零件实测。简化 CAD 可能省略螺纹等细节，不把显示模型当成制造精度证明；导入 Blender 前核实格式支持，必要转换后复核单位和尺寸。

### R6 Adafruit Learning System：电子外壳的完整案例

[3D Printed Case for Adafruit Feather](https://learn.adafruit.com/3d-printed-case-for-adafruit-feather?view=all)

该案例包含配件、可调整 CAD、打印和装配步骤，可作为学习电子外壳布局及模块化交付的入口。用户选择灯光、显示或控制功能时，查实际使用模块的型号与教程；借鉴电池、接口、安装座和装配顺序，不照搬案例设备的切片设置，也不自动把普通文创改成电子产品。

### R7 Blender 与网格分析：检查方法与工具能力

- [Mesh Analysis](https://docs.blender.org/manual/en/latest/modeling/meshes/mesh_analysis.html)：厚度、悬垂和相交等分析；按实际 Blender 版本读取。

- [3D Print Toolbox](https://extensions.blender.org/add-ons/print3d-toolbox/)：打印相关几何分析、编辑和导出工具；核对当前插件版本及兼容性。

- [Trimesh 官方说明](https://github.com/mikedh/trimesh/blob/main/README.md)：网格读取、闭合性、连通体、距离与截面等分析能力；是否可用还需核对本次所需依赖。

具体报告读取、只读分析、STL 诊断去重及保护区比较按 [工具规则](modeling-tools.md) 执行。用于选择检查手段，不把安装所有插件作为前置要求；新增组件按 [环境配置](setup.md) 先说明并确认，可用能力直接复用。自动修复可能改变开口或细节，应在副本上处理并复查。统计通过、着色平滑和切片成功都不能替代外观、接口及实物功能验证。

### R8 Bambu：切片操作与设备排错

- [Bambu Studio 官方文档入口](https://wiki.bambulab.com/en/software/bambu-studio)

- [Bambu 官方打印质量问题索引](https://wiki.bambulab.com/en/knowledge-sharing/common-print-quality-problem)

- [Bambu Studio 官方仓库](https://github.com/bambulab/BambuStudio)：文档入口、版本说明及问题跟踪，可辅助核对软件行为。

- [官方命令行说明](https://github.com/bambulab/BambuStudio/wiki/Command-Line-Usage)：配置加载、摆放、指定盘切片及工程导出的查证入口；完整配置与继承型预设的区别按文档核对，采用前验证本机版本和默认行为。

- [官方 3MF 读写实现](https://github.com/bambulab/BambuStudio/blob/master/src/libslic3r/Format/bbs_3mf.cpp)：用于核实工程／对象配置、引用及面级标记等实现细节。应定位适用版本，不能把 master 实现视为永久稳定的编辑 API；手涂支撑等数据不等于普通参数开关。

按当前软件、设备、喷嘴、材料和实际打印板定位对应条目。Wiki 无法读取时如实记录，可查官方仓库或请求用户提供对应帮助内容，不把搜索摘要当作已读原文。社区问题报告只作为线索，不自动等同于官方结论。具体操作仍按 [Bambu 流程](bambu.md) 验收和复查，资料阅读不授权发送打印。

#### 官方预设与具体耗材资料

[Bambu Studio 官方 BBL 配置目录](https://github.com/bambulab/BambuStudio/tree/master/resources/profiles/BBL) 按 machine、filament、process 分别提供设备、耗材和工艺配置。它是版本化配置来源，不是针对任意模型的最佳参数库；使用时匹配实际软件与配置版本，解析继承及工程覆盖，具体流程见 [切片参数决策](slicing-parameters.md)。目录链接指向 master，不能视为当前安装版的固定版本。

耗材和打印板资料按实际品牌、系列、型号查其制造商官网产品页、技术数据表（TDS）及使用指南，并在来源记录中保存具体链接与版本。查询重点为推荐打印条件、干燥／冷却要求、板材兼容性与使用限制；“PLA”等材料大类或相似商品不能替代具体系列。找不到确切资料时保留缺口，使用可说明适用条件的基准或受控试验，不编造厂家建议。

设备／材料预设提供起点，质量问题文档帮助诊断，试样提供当前条件下的证据；三者分别标注，不把社区经验或单次试打升级为官方标准。

### R9 507 Mechanical Movements：运动原理灵感

[507 Mechanical Movements 索引](https://507movements.com/toc.html)

在共创中探索旋转、往复或其他运动转换时查示意及可用动画，帮助解释候选机构如何工作。它不是 FDM 公差、材料强度或可直接打印的机构库；选中原理后另做真实尺度、连接、运动空间和制造验证。

### R10 CyberBrick：可选动态与电子扩展

- [官方硬件 CAD 与规格发布入口](https://forum.bambulab.com/t/cyberbrick-hardware-cads-and-specifications-available-now/153807)：这是历史发布公告；采用时继续核对当前产品页文档与硬件版本，不把早期资料视为最新版。

- [官方控制器代码与文档](https://github.com/CyberBrick-Official/CyberBrick_Controller_Core)：按需要读取 docs 与对应应用说明。

仅在用户提出电动、遥控、可编程互动，或在共创中明确选择这一方向时进入。它是可选的硬件及控制方案来源，不是造型生成工具，也不是静态产品或手动活动关节的必需组件。

### R11 MakerLab 参数化模型编辑器与 BOSL2

需要可调整的安装座、内胆、铰链或配合试样时，可按 [协同建模](hybrid-modeling.md) 的来源与执行工具选择原则评估 MakerLab 及其支持库；不将该平台设为 Blender 代码结构的默认前置。优先复用适用的成熟结构，执行环境按现有能力、修改与复现便利性确定。平台是生成与编辑入口，BOSL2 是社区结构库，具体模板另有作者和许可。按 [活动结构与参数化零件](parametric-structures.md) 核对版本、留存源码及查阅一手链接；它不是任意网格的自动参数化工具，不默认所有模板开放源码。

### R12 Flexi Toy Maker：可选分节玩具生成

适用于用户选择的分节、可弯曲玩具方向；共创阶段可查官方能力，模型生成须等待前置图纸及路线验收。它不是精密承重机构库，不假定开源、可控公差或自动化接口存在。入口与限制见 [活动结构与参数化零件](parametric-structures.md)。

### R13 解压玩具与 EDC 结构参考

[按动作、来源和验证阶段查阅](fidget-edc.md)：先用已核解压案例入口选择 M05／M06／M07、M12 连续翻折及 M13 外购键轴按压接口等卡片，再按组合玩法判断新增依赖；基础参考包含 dotSCAD、BOSL2、带非商业条件的 OpenSCAD Fidget Toys、BYU 柔性机构原型、Adafruit 轴承教程、磁吸作者资料，以及模型发现平台。逐项区分源码、许可和实物证据，不能将“免费模型平台”统称为开源结构库。机构试样仍受图纸、成果及打印授权约束。

### R14 CadQuery：可选精密功能部件

- [官方项目](https://github.com/CadQuery/cadquery)：Python 参数化 CAD 能力与许可证说明。
- [官方导入导出文档](https://cadquery.readthedocs.io/en/latest/importexport.html)：参数源、STEP／网格交换及细分误差的区别。
- [官方安装说明](https://cadquery.readthedocs.io/en/latest/installation.html)：按实际版本检查 Python、平台与依赖兼容性。

在分工或草模阶段确需精密功能部件时查阅，按 [CadQuery 支线](modeling-tools.md#3-cadquery可选的精密功能部件支线) 选择、执行并回到 Blender 整合；不作为所有文创的必需环境，不让资料查阅授权提前建模。参数化 CAD、离散网格、切片工程及实物试配分别核验。

- **共创与参数阶段：** 比较它能否减少自行设计及装配负担，查实际接口、运动空间和零件数；已有简单可靠方案更合适时沿用，不强制模块化或打印整套框架。只查资料，不提前生成项目几何。

## CyberBrick 扩展的执行边界

1. **用途阶段选路线。** 在确有动态需求时比较纯机械、普通驱动配件和 CyberBrick 等适用方案；解释新增硬件、预算、体积、供电与控制复杂度。用户选择后才纳入设计，拒绝或已有明确选择时不反复推销。
2. **参数与图纸阶段核实硬件。** 确定实际模块型号、数量、版本、尺寸和安装方式；按任务核对供电、电流、驱动能力、动作范围、接口与软件支持。先在二维设计中安排模块空间、走线、开关／充电接口及拆装维护路径，再验收图纸。资料不足的关键条件标为待核实，不靠外观猜测。
3. **建模阶段使用真实参照。** 图纸验收后，在 Blender 中以经核实的模块 CAD 或尺寸样板检查固定座、运动和装配空间；区分打印件与购买件。Tripo 可生成外观，精确硬件接口默认由 Blender 代码建立；已选 CadQuery 支线可先生成接口部件，最终仍在 Blender 整合与验证。STEP 等文件先确认实际导入或转换能力，不能假设原生支持。
4. **软件与硬件接入按需确认。** 阅读资料不需要安装 CyberBrick 软件；需要接入时先检查现有环境，说明具体官方组件、版本、兼容性、安装和缓存位置及配置变更，按 [环境配置](setup.md) 的确认原则执行。购买配件、刷写固件及实际通电／驱动动作分别依据明确授权；不因用户选择该路线而自动执行，不假设已有 MCP 或远程控制能力。
5. **分开报告验证。** 打印几何、机械装配、供电／控制配置和真实动作效果分别记录。切片通过不证明电子功能可用；设备不可访问时交付接线、装配或程序说明，并标明未验证项。动态项目需要的调试成果同样先展示验收，再进入下一任务。
