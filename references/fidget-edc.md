# 解压玩具与 EDC 结构参考

本分支用于用户选择的随身把玩、桌面触觉互动，或在原实用产品上加入解压功能。EDC 在此指日常随身小物的便携与使用场景，不指固定机构类型。允许用户将把玩本身作为用途，不强制增加收纳等附加功能；未选择该方向时不把已有产品改成玩具。资料维护日期：2026-11-13（来源核查范围见各条目及机构卡）；本包只含原创归纳和链接，未自行实物试打以下模型；软件验证见各卡；已有作者实物记录的具体候选见 [机构卡片](mechanism-library.md)，作者证据与本项目实测分别登记。

## 共创入口

用途与互动偏好统一按 [标准共创](co-design.md) 询问，本文件只补充机构参数、来源和手感验证；根据主体特征推荐玩法的映射维护在标准共创中，具体新增来源见 [文创玩具机构](toy-mechanisms.md)，下方只提供已有卡片的选用入口，不复制其详细证据与参数。沿用已确认动作、声音、携带与外购件偏好；选中解压机构不允许提前生成几何。

## 六类结构与验证重点

以下是设计方向，不表示每类都有已验证、许可一致的现成模板。

| 编号／方向 | 可融入的文创形式 | 需要确认和试验 |
|---|---|---|
| K01 按压点击 | 标志部位作为按钮、键帽式包挂 | 外购轴体或纯打印弹性件；行程、回弹、误触、声音、固定接口 |
| K02 滑动／套层伸缩与磁吸段落 | 浮雕双层牌、口袋滑块、手动拉伸的层叠摆件 | 直线滑块与套层伸缩分别判断；导向、防脱、行程／限位、运动空间、滑动阻力、收合卡滞及夹点；使用磁铁时另核实际尺寸、极性、封装及固定 |
| K03 棘轮／定位旋钮 | 花纹圆盘、旋钮包挂 | 单向或双向、段落数量、回差、棘爪弹性、噪声与磨耗 |
| K04 旋转环／齿轮拨轮 | 同心轮廓、齿轮主题外壳 | 轴承或打印轴、轴向防脱、转动间隙；齿轮模数、齿数、中心距与啮合 |
| K05 翻折／无限翻转 | 分块图案、可折叠掌中小物 | 铰链拓扑与朝向、全程干涉、夹手位置、开合耐久与挂绳避让 |
| K06 柔性回弹／双稳态 | 主体局部可按压、拨片切换 | 柔性梁形状、材料、打印层向、位移、是否能保持两种状态及疲劳 |

解压机构与文创外观分别保留可编辑版本；新增装饰不可侵入运动包络、改变弹性梁或覆盖轴孔。缩放外观后重新设计实际接口和配合，不能同比缩放轴体、磁铁和轴承。齿轮尺寸通过相容参数调整，不能独立拉伸某个齿轮后宣称仍可啮合。

## 伸缩与嵌套玩法的资料状态

已具备设计源和明确许可、附制作自述的候选可查 M14；其双锥环允许轴向滑移并翻转，不能冒充长行程管式伸缩。套层升降容器可查 [M15](toy-mechanisms.md#m15--套层升降与转位保持-collapsibasket)，已完成最小依赖默认几何复现，但实际保持力和寿命仍未知；剪叉抓手继续查 [W15](mechanism-candidates.md)，仍待补齐采用条件。

[W13／W14 待核查卡](mechanism-candidates.md#w13w14轻质套层伸缩玩具)补充轻质手动拉伸／收合方向；W13 已读取公开 SCAD，但缺明确许可及实物证据，W14 仍为未完成原站核实的发现线索。它们可支持玩法讨论，不进入上方成熟案例表，也不能因有源码或参数化入口就直接改作。使用前按卡片补证；适配后的运动与外观在 Blender 统一验收，原有逐步确认与按改动验证保持不变。

## 组合玩法与实现代价

先定义用户动作和反馈，再选机构，不把“功能越多”作为目标。以下组合是设计线索，不代表全部已有可直接套用的模型：

| 组合 | 推荐方式 | 验证边界 |
|---|---|---|
| 旋转＋磁吸段落／声音 | 优先评估 M06 同一核心已有的反馈，不另叠加机构 | 核对磁体、极性、间隙和声音偏好；磁吸段落不冒充棘轮或两态锁止 |
| 齿轮把玩＋杯垫用途 | 可从 M07 改外围主题装饰 | 旋转不影响空载稳定与承托面；实际盛杯时另查防滑、稳定、温度，不能以把玩通过代替杯垫验收 |
| 滑动＋端点点击 | 先比较独立反馈与由滑动触发的反馈，避免无收益联动 | 当前库没有覆盖任意组合的整套成熟卡；新增复位、防脱或锁止须按改动范围验证 |
| 翻折＋图案显露 | 可从 M12 的非配合表面设计分块图案 | 保留翻折拓扑、连接核心与间隙；不因只改装饰就忽略闭合时碰撞 |
| 按压带动旋转 | 作为进阶玩法候选，先查具体传动核心 | M13 仅提供键轴定位，不证明能驱动旋转；新增传动、限位及失效状态需要对应证据 |
| 关节弯曲＋局部旋转／按压 | 只有新动作与主体特征匹配时才提出 | 检查握持、相邻关节净空、载荷与总件数；独立动作也可能因外壳或受力相互影响 |

先比较满足体验的单机构方案；用户愿意增加玩法后，说明独立动作还是耦合动作、基础还是进阶、实际件数与外购件。两个核心各自有实物记录，不证明组合已经验证。按 [改动范围](mechanism-reuse.md) 只检查新增依赖和受影响项，未改且仍适用的证据沿用；涉及多个来源时分别核对许可的组合与发布条件。组合讨论在原有方案确认中完成，不增加重复问卷。

## 可查阅来源与许可分层

### F1 开源参数化库：dotSCAD 与 BOSL2

- [dotSCAD](https://github.com/JustinSDK/dotSCAD)、[fidget_star 源码示例](https://github.com/JustinSDK/dotSCAD/blob/master/examples/spiral_polygons/fidget_star.scad)、[库许可证](https://github.com/JustinSDK/dotSCAD/blob/master/LICENSE)：核查到 LGPL v3 许可证文本；示例提供嵌套星形几何的可调源码，可研究层数、间距和轮廓关系。使用时核对具体文件许可、依赖和提交版本，不直接采用示例尺寸或推断耐久。

- [BOSL2 齿轮文档](https://github.com/BelfrySCAD/BOSL2/wiki/gears.scad) 与已有铰链资料：用于构造旋转和翻折机构的基础零件，按 [参数化规则](parametric-structures.md) 核对库版本、许可和接口；它不是已测试的完整 EDC 成品库。不能假定 MakerLab 内置 dotSCAD 或支持全部最新 BOSL2 函数。

### F2 公开源码、非商业条件：OpenSCAD Fidget Toys

[x86-39/openscad_fidget_toys](https://github.com/x86-39/openscad_fidget_toys)、[LICENSE](https://github.com/x86-39/openscad_fidget_toys/blob/main/LICENSE)。

仓库列有无限翻折、旋转环／方环及螺旋发声结构，适合了解部件关系；核查到 CC BY-NC-SA 4.0。应标为“公开源码、非商业条件”，不能与无限制商用开源混称。采用时检查子模块依赖及各文件说明。需要出售产品或发布衍生文件时，先核实许可是否适合；不适合则另选许可兼容方案或联系作者，不将其并入本 skill 的 MIT 授权。

### F3 柔性机构原理与研究样件：BYU CMR

[Maker Resources 入口](https://compliantmechanisms.byu.edu/maker-resources)、[官方历史原型文件页](https://llhwww.groups.et.byu.net/powerpack.htm)。

用于研究双稳态、弹性回位及柔性结构。核查时 Maker Resources 页面无法读取；历史页可读，列有双稳态和弹簧等 DXF／VNC 原型。它们不等于当前 FDM 成品或通用开源授权。需要具体设计时读取作者原始模型页及其许可；未核实前仅作原理查阅入口，不下载改作后宣称可商用。材料和层向改变后，弹性与寿命需重新试验。

### F4 按机构查作者教程：轴承与磁吸

- [Adafruit — 3D Printed Fidget Spinner](https://learn.adafruit.com/3d-printed-fidget-spinner)：轴承式旋转、打印件与外购件装配的教程入口。具体 CAD 和文件许可另核对，不把教程中的轴承型号当作全部旋转玩具的默认值。

- [Kool Fingers — Printing Clickers](https://koolfingers.com/3d-prints/printing-clickers/)：磁体与不同接触表面产生触觉／声响反馈的作者说明。页面注明非商业使用及 CC BY-NC-SA 4.0，并说明相关专利主张；作为有条件的学习参考，不称为自由商用结构库，不捆绑其模型。

### F5 模型发现平台

[Printables](https://www.printables.com/)、[MakerWorld](https://makerworld.com.cn/)、[Thingiverse](https://www.thingiverse.com/) 用于发现具体作者及模型。检索可按动作组合：fidget clicker、magnetic slider、ratchet fidget、rotating rings、infinity cube、bistable compliant mechanism、telescoping fidget、collapsible nesting toy。

它们是模型分享／发现平台，不是统一许可的开源结构库。优先选有明确作者、可编辑源、装配说明和实物反馈的条目；免费 STL、网页生成器可用、源码可见、允许改编和允许商业用途分别记录。未给许可的公开代码不能自动视为允许复用；只有渲染或下载量的条目不能标为实物验证。按当前项目查找具体来源，避免将整个平台全部加入必查流程。

## 阶段安排与手感验证

- **共创与参数：** 确认动作和体验目标、便携尺寸、附加配件及来源许可。图纸展示操作位置、关键剖面与运动状态；原有主视图、多视图和参数图逐项验收保持不变。

- **图纸与路线验收后的建模：** 对不确定的手感机构按 [试样子流程](modeling-plan.md) 制作真实尺寸核心样件；复用该流程的环境前置、逐节点验收和返回位置，不另设一套打印顺序。

- **试样反馈：** 记录实际材料、喷嘴、层向和配件；对照用户目标记录回弹、段落感、声音、阻力、松旷、防脱、磨耗和卡滞。能观察或测量的给证据，未测试的标明。短期循环的次数与结果只能说明本次试验，不能外推长期寿命；渲染、运动动画和切片通过不能证明手感合格。

- **外观整合与复验：** 保留已通过的机构参数，装饰、包覆或换材后按 [改动范围](mechanism-reuse.md) 检查受影响的运动和手感；适用实物证据可沿用，不把所有外观修改都变成整套机构重试；外观大改先返回受影响二维设计。用户暂不试打时按试样子流程明确延期范围，状态保持“手感／耐久待实物验证”。

- **随身使用条件：** 根据实际使用对象检查边缘、挂接、口袋勾挂与夹手位置；涉及磁铁或小零件时设计可靠固定与防脱，面向儿童时不能直接沿用成人 EDC 样件。把玩体验不表述为医疗或治疗功效。

项目记录沿用 [项目记录](project-record.md)：补充机构编号、体验偏好、来源与许可、参数版本、试样结果和待验证项。公开包不复制第三方模型、代码、图片或完整教程。
