# Bambu Studio、切片与物理打印

## 核实当前能力

助手先检查本机 Bambu Studio 版本、当前工程和可用控制工具，按 [代码配置与切片](slicing-automation.md) 准备参数。配置验收后优先用命令行切片；遇到版本差异，由助手验证可用参数并在副本中试切。命令行无法可靠完成的步骤由助手操作 Bambu Studio 界面继续。离线配置和切片无需打印机在线；发送打印前另行核验连接与授权。

用实际工程与产物验证接口。确需用户授予权限、安装组件或完成助手无法操作的界面动作时，说明具体缺口，只请用户完成该项，然后由助手接续。关键设置变更、阶段成果验收和物理打印授权仍由用户决定。

## 遇到参数或打印问题时查阅

按 [阶段与问题参考库](resource-library.md) 的切片与实物反馈路由，读取对应软件版本的 Bambu 官方操作和质量问题资料；材料及方向问题补查 Prusa、伯克利与实际耗材厂家。核实条件后再改变相关设置，不将其他工艺或机型的建议直接套用。记录引用结论与切片／实物证据的区别；查阅发生在当前任务内，不提前切片或发送打印。

## 参数决策与配置依据

按 [切片参数决策](slicing-parameters.md) 在打印方案阶段只读核对本次基准，包括实际设备、喷嘴、打印板、具体耗材及软件／预设版本，解析继承和工程覆盖后的有效值。围绕产品目标查原文，在摆盘与配置成果中展示“原值 → 当前值 → 来源／假设 → 代价与待验证项”，确认后才切片。未知生效值如实标记；不额外增加确认阶段，不将局部配置文件视为完整预设。

切片及实物反馈与模型、工程和参数版本关联；需要试样时复用现有子流程。详细诊断表、试验变量及经验复用条件统一维护在参数决策文档，操作与失败恢复继续按本文件执行。

## 成果验收与阶段交接

打印方案、摆盘与参数配置、切片结果是独立成果。每项完成后展示、询问满意度和修改意见，等待明确接受再开始下一项；摆盘尚未验收时不能先行切片。软件操作成功只证明技术步骤完成，不代表用户满意。切片验收和物理打印授权都满足后才发送。同一任务内的读取、设置、检查、保存不需每次点击都征询。

## 机构试样打印

来自 [试样子流程](modeling-plan.md) 时，仅使用当前已接受的样件及其参数，不要求整件外观细化完成。导出检查、打印方案、摆盘／配置、切片验收及物理授权仍逐项执行；反馈记录对应试样编号，通过或延期结论验收后返回约定整件节点。试样打印授权不自动覆盖整件打印，试样结果也不证明整件已合格。

原位打印活动结构需重点检查运动间隙是否被首层扩张、支撑或修复封闭，并核对各活动实体的防脱与支撑清理；保留有意分离的实体，不以自动合并作为修复目标。

## 代码准备工程与界面交接

执行细则以 [代码配置与切片](slicing-automation.md) 为准：打印方案接受后，在有效工程副本中批量写入已核实的完整预设与逐件设置；作为 Bambu Studio 工程打开，核对本轮对象、盘、材料、实际生效配置和必要警告，展示验收后再调用切片。参数准备和切片是分开任务，不能用一次命令或脚本绕过配置确认。符合版本与结构时使用 [包内项目适配器](bambu-adapter.md)，先 inspect／prepare／open，按执行文档判定是否需要完整另存回读，核对并验收后才单独 slice；SHA-256 只绑定输入版本，不能证明用户已同意。

工程格式、对象字段与面级手涂数据按实际版本验证；保留用户摆盘、无关配置和原文件。代码修改后重新读取结果，切片缓存失效按执行文档处理。无法安全自动处理的特殊字段保留界面操作，不退回整套流程逐项重填。命令行日志／结果中的警告与界面弹窗同样需要检查，离线运行没有弹窗不等于没有问题。

## 可见步骤与失败恢复

控制桌面切片器时，将流程分为“确认当前工程与本轮清单 → 按需导入／更新选定件 → 核对零件 → 检查或完成摆盘 → 配置设备/耗材/打印板 → 切片 → 逐层预览 → 保存工程与切片”。每步用软件状态或实际文件确认完成，再进入下一步。导入对话框和主窗口的焦点要分别确认；路径没有进入文件名框、导入后零件数不对时立即纠正。某一步重复失败时停止同样的输入方式，由助手改用经验证的文件打开方式或界面操作；仍受阻时记录实际卡点。不要用大量重复截图或无关检查拖延下一步；已完成的摆盘和当前软件配置应沿用，不擅自从头重做。

## 弹窗、警告与自动处理

通过界面导入、设置、摆盘、打开工程或切片后，检查当前窗口、弹窗及警告列表；命令行／离线任务则检查退出状态、结构化结果、日志和实际输出，必要时打开工程定位，不能因没有弹窗忽略警告。先读取完整提示和受影响对象，再执行对应操作。不得盲点确认、关闭提示后声称问题解决，或在弹窗遮挡时继续向主窗口输入。保留原始模型和切片工程，自动处理在工作副本中进行，记录提示、选项、对象及处理结果。

- **面数过多。** 出现简化建议时，使用当前软件提供的模型简化功能，选择细节保留最高的等级；若以误差或比例表示，先核实其含义并采用最保守、保留细节最多的设置，不把最大减面率误当作最高细节。不猜测固定按钮名称或数值。简化后核对轮廓、细纹、孔槽、榫卯配合、尺寸及零件数量；若仍过慢或损失重要结构，撤销并返回建模阶段处理，不擅自逐级降低细节。

- **非流形边或网格损坏。** 提示提供“修复”或等价功能时，先在工作副本中执行自动修复。完成后复查缺面、裂缝、孔槽通畅、薄壁、分件与接口，防止自动补面封住功能开口或合并独立零件。修复不可用、失败或改变关键几何时，保留原文件并返回建模阶段定位，不反复点击或仅凭弹窗消失判定通过。

- **热床温度或板材配置报错。** 核对实际装板、当前打印板预设、受影响耗材及其适用温度依据，在对应耗材设置中调整该打印板的热床温度，分别核对首层与后续层；多耗材逐一核对。预设选错时先纠正预设，保存到当前项目或用户耗材副本，不覆盖无关预设。不把温度设成通用常数，也不通过随意升降温度消除提示；依据不足时查证官方配置或询问实际装板。硬件加热、传感器或通讯故障不能当作温度配置错误处理，应停止发送打印并说明具体故障。

上述操作属于对应导入、配置或切片任务内的修复，不要求每次点击都批准，也不跳过阶段成果验收。修复或简化后保存独立切片工程，注明它与源模型的差异；几何或参数变化后使旧切片结果失效，按相应阶段规则重新检查和切片。切片尚未获准时不因处理弹窗自动启动；已授权的切片任务内可修复后重切，最终仍需展示并验收新结果。涉及外观或接口设计改变时返回设计确认。

## 本轮打印范围与用户操作续接

整件沿用已接受的色区拆件或保持一体结论，以及导出检查通过的零件编号。打印方案中维护本轮清单：部件编号／文件与版本、数量、纳入或排除、实际材料／颜色、目标耗材槽位及所在打印盘；已知选择直接沿用，缺口才询问。展示或按颜色命名不证明材料映射正确，不把整套模型默认加入本轮。区分打印盘编号、切片器材料编号与机器实体供料槽；用户所说“料盘／槽位”有歧义时先核对，按实际设备和界面确认映射，不凭编号相似推断。无需槽位的设备按其实际供料方式记录，不强制多料系统。

先读取当前工程和实际摆盘状态，核对本轮部件、数量、模型版本及材料分配。用户已手动完成导入或自动摆放时，检查并接续现状；不重新导入、清盘或自动摆放覆盖其操作。实际模型版本确实变化时，仅按已授权范围替换受影响件，保留其余位置及设置并复核；不能为保留旧摆盘而沿用失效模型／切片。只报告“已摆放”不等于成果接受，未明确验收的配置仍展示确认，已接受且未变的同版本不重复询问。

按清单处理本轮选定件；排除件、展示副本和辅助物不进入实际切片／发送范围，无关盘无需删除。摆盘及切片后核对清单，发送前复核目标盘和供料映射，防止发送整个工程的其他盘。装配位置、拆件展示位置与实际打印朝向分别保存或记录；不从 Blender 展示位置直接推定打印方向。

## 导入和配置

确认目标打印机型号、喷嘴、实际装载的打印板、每个零件对应的材料预设与耗材槽位、颜色/多色系统配置及可用打印体积。凭据按需使用，不写入技能、项目记录或聊天输出。用户已有配置优先沿用；无法确定时不要静默选择其他打印机配置。

导入或续接后按本轮清单检查尺寸、数量和零件结构，确保单位正确，颜色分区和装配关系未丢失。按 [逐部件参数决策](slicing-parameters.md) 根据各件精细度、结构复杂度、功能和支撑可拆性规划朝向、分盘、参数与支撑，再核实当前软件支持的设置范围；不能仅按颜色同盘并套一组设置。参数注明选择依据。花瓶模式、多色和嵌件需使用对应产品要求。对已登记采用颜色分区／多材料实现的必留特征，核对实际对象材料或涂色结果及本轮切片，不将 Tripo 贴图自动视为打印色区；实体细节或嵌件缺失时返回对应建模成果，不能用预览颜色掩盖。

打印板类型与材料预设决定可用温度范围；出现温度或板材不匹配警告时，先确认实际装板和当前预设，再修改对应材料在该板上的首层、后续层设置或选择正确预设。不得把任何一次打印的热床温度写成通用常数。根据颜色、材料、打印方向与装配方式决定同盘、分盘或一体打印；分盘后逐盘核对零件数、材料槽、朝向与是否越界。把本轮各盘保存在同一份可编辑的 Bambu Studio 工程中。回到「准备」页按盘号核对零件、摆放及生效设置。切片日志或退出码不能替代逐层检查。

## 切片检查

配置已经接受后执行本节。先按 [输出参数与预览核验](slicing-automation.md#41-核对实际输出与参数差异) 自动比较本轮有效参数与已接受配置，确认选定盘、零件及材料映射，确认预览读取本轮实际 G-code；自动重切的结果另记版本。完整差异保存在报告中，只展开实际修改、未解释差异和影响判断的未知项，不逐项人工复述未变参数。

按以下顺序集中检查，不把“逐层预览”执行成对每个零件逐层逐帧截图：

1. **每盘总览与每件首层。** 核对版本、件数、朝向、越界、实际贴板接触和承托；优先发现会导致脱落或起始悬空的问题。设置了裙边／筏底不等于已生成，宽支撑底座也不等于与模型连通的附着面。检查真实路径、首层及支撑到模型的过渡，不能只检查被警告点名的零件。
2. **只深入实际存在的风险。** 对悬垂／桥接检查承托，对薄壁、细齿、孔槽、活动间隙或连接部位检查关键高度与上下过渡，对小榫槽查看榫根、槽口薄边及盲槽槽底是否有连续的实体挤出路径，对支撑检查接触及拆除空间。多色或嵌件才查对应换料、冲刷或暂停；没有相关结构不展开该分支。各件数量、摆盘与接触均核对，几何、方向和工艺条件相同的重复件可成组作功能细节检查，特殊位置另查。
3. **局部改动按依赖复查。** 对照上次已核对版本，深入检查受影响部件／区域及参数依赖；方向、支撑、层高、材料或全盘工艺变化影响到的范围一并复查。新切片仍核对总览、首层和实际参数，未变化的几何深检可引用原证据；不因一件改变而重做全模型几何审计。需要重切时由软件生成对应盘的完整新路径，不拼接新旧 G-code。

在受影响区域的切片预览中，对照[支撑方式与接触位置](slicing-parameters.md#支撑方式与接触位置)核实必要悬垂获得承托、支撑实际落点避开受保护的细节，以及工具和支撑块都有进出空间。对必须保留的局部接触，重点查看拆撑施力方向是否会撬动、拉断或误剪零件本体。发现问题时只在已授权范围内修改；改变设计、朝向或方案取舍需回到对应确认。对比候选仅在用户已要求、已有方案未满足目标或发现明确问题时进行，不默认每轮多方案切片。

**满足即结束内部检查：** 当前版本与本轮清单正确；无未解释的工艺参数漂移或路径完整性问题；已查看本轮真实首层及适用风险区；耗时、耗材与警告的含义／待验证项已说明。达到这些条件就保存并展示切片成果，等待用户验收，不因“再放心一点”追加截图、全量回读或重切。实物性能仍未知时明确为试打候选，不冒充已验证成品；关键问题未解决则交付具体阻断结论与下一方案，不能以赶时间当作通过。

警告与差异按其影响处理：路径／参数问题先定位解决；设备或材料交接资料缺口阻止正式发送；辅助统计异常可在核实可用估算后注明未知；未知告警先判读，不能自动当无害，也不一律重切到零告警。同一版本、配置和问题没有新输入或有依据的新假设时不重切；同一办法连续无改善时停止重复尝试，回到可靠基准选择已验证回退或提出下一项取舍。各独立成果的明确验收不变，技术自检不新增审批节点。

### 每盘切片文件交付

每个实际切片的盘分别标明盘号、部件和版本，给出两个能打开的文件链接，先工程、后 G-code：

1. **可编辑 3MF 工程（改耗材／调参数）**。各盘条目的第一项默认链接同一份已验收工程，并注明要选的盘号。作为项目打开后，应能在「准备」页切换各盘、选中实际模型并修改摆放、耗材预设、支撑及逐件设置。若按主流程约定分建工程，则链接包含本盘的那一份。
2. **本盘 G-code（看已切路径／确认后打印）**。提供该盘本轮生成并核验的正式切片文件，如 Bambu Studio 的 `.gcode.3mf`，或目标工作流支持的 `.gcode`。用本轮切片记录核对工程版本、盘号和实际路径。若另外制作了仅供查看的副本，列在两份正式文件之后并标明“仅供预览”；只供查看的适配包不能充当正式打印文件。

调整参数时从共用工程选中目标盘，确认设置的生效范围。改动工程级耗材或工艺时，核对所有引用它的盘。更新工程版本，仅重切受影响的盘并更新其 G-code。对于沿用的 G-code，核实该盘的几何、摆放和生效设置均未改变，保留实际切片来源版本及沿用依据。缺少含几何与设置的工程、缺少正式路径文件或两者版本不符时，标明受影响盘并补齐后再记为完整交付。发送打印仍按本轮授权执行。

随文件给出清晰总览及必要局部图、简短参数／问题表。完整日志与自动报告保存一次并链接。用户未要求且问题可清楚表达时，不另做交互网页、多套重复报告或网页布局测试。

## 表面质量方案比较

本节仅在用户要求比较、现有方案未满足目标或发现相关缺陷时使用；普通合格结果不自动增加候选切片。

对浅曲面上的“等高线”层阶、低多边形造成的折面、平顶铺线和支撑接触痕迹分别诊断：几何折面需修模型；曲面层阶可比较局部可变层高、整体薄层、改变摆放方向或拆件；平顶铺线与悬垂痕迹使用对应切片/结构方法。增加模型面数或降低速度不能直接消除层高造成的台阶，熨烫不能当作浅曲面的通用修复。

对每个候选至少展示受影响外观面的切片预览、预计时间/耗材、支撑与装配代价。可变层高或倾斜可能改善某一曲面，却增加时间或使另一面需要支撑；预览上的差异也不能替代实物效果。用户觉得改进有限时保留原工程和设置，切回原方案，不以投入的工作量强推新方案。对昂贵或耗时方案优先制作关键局部的原尺寸试样。

## 发送与跟踪

用户已验收当前切片结果、明确授权该次物理打印、设备和关键设置已确定且切片检查通过后才发送。若还缺授权，先准备可审核的项目、预览、耗材和时间，再询问是否发送。各阶段成果须按交互规则验收，阶段内的普通操作无需逐次批准。

发送前确认设备状态和材料匹配，并核对当前文件是已验收的正式产物；“仅供预览”的适配副本不进入发送流程。关键设备／材料信息缺失或参数漂移尚未解决时，按 [输出核验与回退](slicing-automation.md) 处理，不能由预览成功推定可发送。记录设备、模型版本、项目、设置与实际任务状态；成功发送不等于打印完成。仅在有设备状态证据时报告启动、完成或失败。当前会话无法持续跟踪时明确状态和检查方式，不声称正在持续监控，不自行创建自动化。

## 实物反馈

收集实际配合、稳定性、承载、屏幕/按钮遮挡、外观、手感、清洁或水密反馈，注明反馈来自切片预览、局部打印件还是完整实物。判断问题来自几何、公差、材料、摆放方向还是切片参数，先改造成问题的那一层，不无依据地重做整个模型。修改关联参数，保存新版，再切片和复验。未试打印只能交付可试打候选，不能宣称已验证实用品。
