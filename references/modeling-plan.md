# 建模分工、独立成果与机构试样

本文件维护当前交付对象、独立候选与内部操作的边界，以及机构试样和返回节点；阶段顺序以 [主流程](../WORKFLOW.md) 为准，部位与工具职责见 [协同建模](hybrid-modeling.md)，确认方式见 [交互规则](interaction.md)。图纸与参数图须分别验收，不能为试样跳过；主体图纸无法表达的内部结构先补二维剖面。

## 建模分工按对象确认

沿用 [协同建模](hybrid-modeling.md) 的路线与部位职责，按对象确定执行工具，不能把 Tripo 与 Blender 列为只能二选一。用途阶段初判职责，完整造型接受后确认必要拆分，完整参数图接受后才落实执行分工与环境；已确认且未变的判断直接引用。

在路线成果中列明各部位生成／代码／保留来源、接口与保护范围、需安装／连接的组件、是否制作派生图、独立候选及试样分支和返回节点。用户接受后按 [环境配置](setup.md) 核验，结果展示验收后才执行下一任务。简单路线跳过 Tripo 组件、生成计划和候选任务，不跳过图纸与草模验收。已有同范围决定沿用，不重复询问。

Tripo 输入、候选、重新生成及已有结构后更换外观，按 [生成与接收](tripo.md) 执行；派生视图范围与验收按 [多视图设计](multiview-design.md)，不在此另维护完整阶段链。试样可按下节先行，不要求为了试样先付费生成外观。

所有代码及外部模型都在 Blender 中进行实际几何检查和修改。Tripo 的候选、比较和重新生成按 [生成与接收](tripo.md)；MakerLab、Flexi 按 [参数化接入](parametric-structures.md)。安装授权、上传／费用授权和成果接受分别记录；新增依赖或实质改变分工时确认相关范围。仅在图纸和分工已接受的环境任务中可进行隔离最小几何测试，不能把测试当草模；早期可行性阶段只读发现能力。

## 执行前确定验收单位

以下属于独立成果，事先说明并单独展示、等待接受：

- Tripo／Flexi 等生成的主体或局部外观候选，或需要用户比较的结构候选；局部图及候选复用同样的独立验收。

- 需要决定外观、机构、功能或装配取舍的零件方案。

- 用于验证配合、回弹或手感的独立试样。

- 已经明确承诺单独交付的参数化模块。

已确认草模方案内、无新增取舍的常规孔槽、轴座或参数化零件生成，可作为当前草模内部操作，在整套草模处验收。生成速度、零件数量和是否使用外部工具不是省略验收的依据。不能在执行后把独立候选改称内部操作；产生新的设计选择时停留当前任务并先澄清。

## 参数状态与试样边界

- **实物硬约束：** 配合物型号、真实外形／接口及安装基准等。缺少会导致样件目标不明确的信息时先实测或查证，不用猜测样板假装适配。

- **已接受设计值：** 用户认可的尺寸和造型选择，尚未实物验证时如实标注。

- **待试验设计值：** 为当前工艺确定的间隙、弹性梁或手感参数。须给出依据、测试范围和目标，由用户接受“用于试验”的数值并在参数图标注；可用于样件建模，不等于整件已验证。

参数确认接受的是版本及其状态，不强制假装所有公差已被实验证实。无需先知道试验结果才能建立测试件。试验参数变化应更新参数表和受影响的二维标注并验收；不重画无关图纸。

## 试样子流程及返回节点

触发：当前条件下缺少可靠配合依据，或机构回弹、段落感、防脱、磨耗等不能从模型确定。先按 [成熟机构复用](mechanism-reuse.md) 核对来源版本、实物证据、原条件与本次改动，形成“沿用结论／本轮检查／必要试样／仍未知”的简短计划。适用证据已覆盖且未受改动影响的内容不重复试打；证据缺失或条件改变时只验证相关功能及依赖，不把未写出的条件视为相同。

功能草模验收后、进入大量外观细化前，识别关节、卡扣、弹片及其他会影响整件设计的高风险结构，列出未验证问题、通过判据及依赖该结果的后续工作。缺少适用实物证据时优先安排原尺寸关键试样；几何上能装入或扣合不能替代定位、保持力和使用工况验证。依赖这些问题的大量精修默认暂缓，已接受范围内不受影响的工作可以继续；不以“草模已接受”自动视为试样通过。

图纸、路线和环境获接受后，可在整件草模之前，或草模验收后、外观细化前安排试样。整体验收后新增的分色接口若需要试配，也复用以下流程，仅验证新增接口及受影响部位。

1. **试样方案验收：** 明确被验证接口／机构、真实尺寸、试验参数、材料与工艺、比较方案、通过判据和试验后返回的整件节点。方案不得暗改已接受外观；需要新的局部图纸先展示验收。
2. **样件建模验收：** 保留接口真实尺度、根部连接、代表性壁厚和整件计划采用的打印方向／层向；保留会影响结果的材料及切片条件。按目标设置必要的安装约束、力臂、施力方向／范围或经说明的等效加载，按 [活动机构检查](blender.md) 覆盖相应极限状态。不能把试样缩成仅能互相扣合、却不承受实际使用作用的两个零件。需等效简化时说明保留条件及无法外推的部分；只做验证目标需要的结构，不要求整件装饰完成。按 [Blender 检查](blender.md) 处理已有几何缺陷，展示尺寸与验证部位后等待接受。
3. **样件导出检查验收 → 打印方案验收 → 摆盘与参数配置验收 → 对试样所在盘执行切片 → 逐层预览与切片结果验收 → 本次试打授权及执行。** 具体操作复用 [Bambu 流程](bambu.md)，各节点不合并，不因小件或测试跳过打印授权。
4. **反馈与参数结论验收：** 记录实际工艺、观察和用户手感评价。失败则提出修订，更新受影响二维依据和试样，重新走相关节点；通过才将结论用于相同条件的整件设计。
5. **返回约定节点：** 回到整件草模或细化；若试样用于整体验收后新增的分色接口，则返回该拆件与装配节点。参数、外观或接口已改变时先重新验收受影响图纸／草模；未变范围的确认沿用。试样成功不等于整件已通过，整件仍完成自身检查与打印验收。

用户暂不试打时，展示“先试样”“保留待验证项，继续不依赖它的指定工作”“暂缓相关结构”等合适选项。若用户要求继续依赖未验证结构的大量细化，先说明具体返工影响并确认继续范围，不自动将一般继续指令解释为接受该取舍。只在用户明确选择后继续其认可范围；不能填补缺失实物硬约束，也不能把手感、配合或耐久标成已通过。后续整件试打仍须另有当前结果验收和打印授权。

只为诊断当前问题调整样件；无法获得有效改善时回到基准、重新评估机构与可行性，不无限累积试验。原位打印多实体、固定连接及活动配合分别遵守 [连接原则](design-rules.md)。
