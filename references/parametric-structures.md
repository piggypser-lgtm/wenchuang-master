# 活动结构、参数化零件与 MakerLab 接入

此分支用于需要尺寸可调、可复用功能零件的项目；不是所有文创的必选路线。沿用 [主流程](../WORKFLOW.md) 的设计优先和逐成果验收，不因在线工具能快速生成而提前建模。

## 1. 共创入口

活动与解压意向统一在 [标准共创](co-design.md) 的用途方案阶段确认。此处只维护所选工具的执行与兼容性；不再次询问相同偏好。固定与活动接口的设计边界统一见 [连接原则](design-rules.md)，分工、候选验收和试样返回统一见 [建模计划](modeling-plan.md)。

## 2. 工具分工与适用条件

| 工具／资料 | 合适的工作 | 边界 |
|---|---|---|
| MakerLab 参数化模型编辑器 | 使用有授权的模板或自行编写的参数化源，调整功能零件的尺寸并生成几何 | 依赖源文件实际开放的参数；不能假定任意图片、STL 或 Tripo 网格能自动变成参数化模型 |
| BOSL2 | 按当前版本文档构造铰链等可复用结构，供 OpenSCAD／兼容平台执行 | 社区维护的开源库，不是拓竹自研结构库；函数可用性和参数含义须逐项核对 |
| STEMFIE | 按零件编号查齿轮、齿条、轴系、锁紧件等实体源，评估机械拼装 | 可选参考源库；按[资料索引 R17](resource-library.md#r17-stemfie可打印机械零件源库)核对格式、许可和具体组合，不假定 MakerLab 内置或 Blender 原生支持 STEP |
| Flexi Toy Maker | 用户选定分节、可弯曲玩具方向后，评估图像生成活动玩具的路线 | 专项生成器；不默认适用于精密承重铰链，也不假设提供源代码或精确接口参数 |
| Tripo 与 Blender | 生成或建造主体外形；Blender 整合功能零件、调整外观、检查真实尺度及可打印性 | 生成成功不等于配合、运动或实物使用通过 |

参数化方向可包括支架托槽与安装腔、容器内胆、铰链、定位销与榫槽、磁铁座，以及多档间隙测试件。它们是可评估的应用方向，不代表平台已有对应模板。现有模板不满足结构、许可或外观要求时，可提出自行编写参数化源或直接 Blender 建模；不能为了套模板擅改已确认设计。

## 3. 生成与 Blender 接收

共创和参数阶段只查资料、模板开放参数及兼容性，不生成本项目几何。造型多视图与参数图分别验收后，按 [建模分工](modeling-plan.md) 确定当前交付对象及独立验收点，再按 [环境配置](setup.md) 核验所需接入。选用 [成熟机构](mechanism-reuse.md) 时先依其原生源码、依赖与版本确定复现路线，再评估适用的拓竹平台及其支持库；不为套平台重写已经有证据的核心或丢弃原生参数源。以需求、许可、兼容性和复现能力决定，不强制采用。

MakerLab／Flexi 接入应核实地区、实际输入、输出格式、账户与所需费用、下载及 Blender 导入方式。需要上传或产生费用时，先展示输入图版本、生成范围、参数、次数及费用上限，确认后执行；用户选择工具或完成登录不能代替生成授权。普通已授权本地参数运算不另设付费确认。缺少自动控制时明确人工交接，不杜撰 MCP／API。

生成后保存原始输出，导入 Blender 核对单位、尺度、朝向、零件数、轴线及基准。Flexi 主体候选和其他独立候选先检查图纸符合性、实体状态及预览，展示验收后才整合；常规内部零件随事前约定的草模展示。结果不符合图纸时说明偏差，留在当前候选修正或提出新的生成计划，不能直接替换已确认设计。失败重试先检查已有任务和输出，不重复提交不明状态的任务或超出授权费用。

整合后检查运动极限、干涉、间隙、壁厚与装配路径，布尔或修形后复查接口。试样按建模计划进入其独立子流程；3MF 预设及装配预览不能替代当前设备、材料和实际导出零件检查。任何外观／机构大改先更新受影响二维依据并验收。

## 4. 版本、来源和可复现交付

使用 BOSL2 或其他库前，核对平台当前内置库版本／提交号、所需函数是否存在、参数定义及依赖是否兼容；不能默认在线平台与最新版文档一致。图纸、路线与环境流程允许几何测试后，在隔离场景测试本项目所需的最小调用；此前仅查版本和文档，不创建本项目几何。版本未知、函数缺失或生成失败时如实记录，提供兼容实现或本地固定版本路线，由用户确认影响设计／环境的变更。

分别登记：

- 平台提供方及地区入口。

- 结构库作者、仓库、实际使用版本／提交号和许可证。

- 模板／模型作者、原始链接、版本和模型许可证；平台可调参不等于模型开源或允许再分发。

需要可复用参数化结构时，保留有权取得的源码、依赖与库版本、参数值和单位、生成步骤及输出对应关系，不能只交付网格。将原参数化源与 Blender 整合文件分别保留；网格导入和布尔修改不会自动回写源码，后续改变接口时重新生成并复核。源文件不可获取时明确无法保证完整复现，提供获许可的开源替代或自行建模选项，不声称已经交付可编辑参数化源。

公开 skill 只保存规则、链接和原创总结；不自动捆绑第三方源代码、CAD 或素材。原有 MIT 许可不覆盖第三方内容，署名、修改和分发条件分别遵守。上传素材、公开发布源文件、付费生成和购买配件按已有明确授权范围执行，不把使用工具的意向当作所有外部操作的授权。

这些链接是查证入口，不是实际接入、生成或打印成功的证据。使用时无法读取的页面应标为未核实，并按当前任务选择其他官方来源或人工交接。

## 桌面数码结构补充

需要模块化收纳、桌边夹持或理线盒时，按 [桌面数码参考](desktop-digital-accessories.md#参考来源与用途) 评估 Gridfinity Rebuilt、modular-clip 或参数化理线盒。它们是按需源码候选，不默认属于 MakerLab 内置库或必装依赖；沿用本文件的版本、许可、参数源留存、生成前置与 Blender 接收规则。接口保持固定但可拆换的模块不自动属于运动机构；总件数、限位和防脱按实际用途判断。

## 解压与 EDC 补充

按压、滑块、棘轮、旋转、翻折和柔性回弹需求另读 [解压玩具与 EDC](fidget-edc.md)。结合声音、手感与携带条件筛选，区分完整成品示例和基础几何库。沿用本文件的版本、许可及逐阶段验收要求；实际手感和耐久单独记录，不由参数化生成成功推断。
