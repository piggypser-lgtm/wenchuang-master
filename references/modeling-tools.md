# 按需几何检查与精密结构工具

在功能分工、环境核验、模型交付检查或导出验证时按问题读取。3D Print Toolbox、Trimesh、CadQuery、SMLib 和 Sand3D 几何函数库都是可选能力；先复用已有可用工具，确有缺口时按 [环境配置](setup.md) 展示方案并确认安装，不把这些工具设为所有项目的前置条件。新增工具不改变图纸、草模、细化与打印验收顺序。

模型路线及结构来源／执行工具的选择统一按 [协同建模](hybrid-modeling.md)；已有适用参数源按原生方式复现，自行编写常规功能结构优先用 Blender，CadQuery 等按收益选择。所有实际模型仍回到 Blender 整合、检查和展示。下面的工具检查属于当前任务内部工作，不替代 [Blender 视觉与功能验收](blender.md)。

## 按问题选择

| 需要解决的问题 | 首选能力与输出 | 不应据此宣称 |
|---|---|---|
| 重复编写拉伸、孔槽、布尔、倒角和部件定位代码 | 可选 [Sand3D 函数封装](sand3d.md)，通过现有 Blender MCP 生成并测量实际网格 | 已安装就全部兼容，函数成功就可打印，或一定节省时间／token |
| 在 Blender 定位薄壁、非预期边界、相交或其他打印相关网格问题 | 原生检查或当前版本 3D Print Toolbox；给出对象、问题区域、检查项及阈值 | 已安装插件就完成检查，或所有提示均应自动修复 |
| 批量检查实际导出文件、比较修改前后保护区 | Trimesh 等已验证读取能力；保存尺寸、连通体、变换及几何差异证据 | 封闭即能打印，单次采样最大值就是完整表面误差上界 |
| 严格孔轴、配合面、关节座或尺寸系列需反复参数调整 | Blender 参数化代码优先；已选择 CadQuery 时使用其 CAD 实体与脚本，再导入 Blender | 通用网格已自动变成可编辑 CAD，或 CAD 尺寸代替实物试配 |
| 多截面渐变和连续圆角需要随参数重建 | 可选 [SMLib 多截面放样](#smlib-多截面曲面)，导回 Blender 核对端部与功能面 | 单个试件的耗时、面数或 token 收益适用于其他零件 |

## 1. 3D Print Toolbox：读取检查结果，定位后修复

按当前 Blender 与扩展版本核实实际提供的检查项、操作入口和报告读取方式，不硬编码未经验证的插件模块或操作符。已有原生方法足够时可以直接使用，不因插件未装就阻断当前检查。

检查前明确对象、真实单位与缩放、源网格还是修改器求值后的打印几何；阈值按已确认尺寸和本次制造条件选择，不沿用无来源的全局默认值。执行后实际读取报告或界面结果，记录检查对象、项目、阈值、问题数量及受影响区域；报告不能取得时说明哪些项目没有证据，不能以工具调用成功声称通过。

对报告指向的元素，在当前拓扑仍对应时选择／定位并查看近景或剖面，区分预期结构和缺陷。活动组件有意分离、容器有功能开口、某些悬垂由支撑处理，均须按设计解释；没有对应壁面的真实缺面不能借“开口”理由忽略。薄壁、相交或悬垂提示须结合实际位置、方向和打印方案判断。

修复在工作副本的明确区域执行。不要把“全部检查”理解为“全部自动修复”，也不直接对全模型执行闭合、全局合并或平滑。修复后重复受影响检查，并复查孔槽、间隙、轮廓和相邻接口；拓扑变化后重新定位报告，不沿用旧面编号。数值通过仍须展示实际几何，真实保持力、强度和支撑可拆性另以适当试样验证。

来源：[Blender 扩展目录](https://extensions.blender.org/add-ons/print3d-toolbox/)、[Blender 网格分析](https://docs.blender.org/manual/en/latest/modeling/meshes/mesh_analysis.html)。访问受限或版本资料不全时标记缺口，依据本机已核实能力执行，不虚构插件的检查覆盖范围。

## 2. Trimesh：导出核验与修改前后比较

Trimesh 是 Python 网格分析库，不是必需的新 MCP 服务。按需在独立项目环境运行；读取、分析与修复分开，不为一次检查改动原文件。按当前版本核实所需可选依赖，无法执行的检查如实标为未验证。

### 保留原件、单位与实例

默认以 process=False 关闭加载时的自动处理，并避免隐式验证／清理；只读检查不能悄悄移除异常值、合并顶点或改变三角面。含多对象或实例的 GLB 等文件先按场景读取，保留对象对应、实例变换和材料信息；不能用不可逆的整体拼接代替零件清单。按当前库版本确认参数实际生效。

单位、轴向和坐标转换从项目与文件格式核实，尤其 STL 不携带可靠的单位定义。把源模型、实际导出物和基准放入明确的同一单位／坐标系再比较；不得凭看起来相近自动缩放，或通过未记录的自动最佳配准隐藏原本不应发生的位置变化。尺寸、世界变换和局部网格分别核对。

### STL 顶点去重只用于明确的诊断副本

某些 STL 按三角面重复存储顶点，未经索引重建时，基于共享顶点的闭合性和连通性判断可能把同坐标边视作未连接。此时同时保留原始读取结果，另建标记清楚的诊断副本，按明确的相同坐标规则或已说明的精度重建共享顶点，再分析拓扑；报告原始与诊断两种结果、去重规则及数量变化。

不跨已知独立零件或运动间隙盲目焊接，不用制造公差直接当顶点合并阈值。无法区分重复存储与有意接触／分离时保留不确定性，回到源对象或 Blender 检查。诊断拓扑不等于原件已修好，也不能自动成为新的打印件；若要采用修复版本，仍按当前模型修改与验收规则处理。

### 输出有适用范围的检查证据

按本次风险读取包围尺寸、零件／连通体数量、闭合性、朝向一致性、退化几何及可取得的距离／截面信息。只调用已验证可用的检查，不把 Trimesh 当作覆盖所有自相交、薄壁或制造问题的万能工具。体积等结果须满足相应几何前提并标注单位，不能据此直接推定带填充和支撑的实际耗材。

保护区比较沿用 [局部修改规则](blender.md)：独立未改部件核对几何及世界变换；同拓扑可比较对应顶点，拓扑变化后重新建立空间／区域对应。采用表面采样时记录基准、保护范围、采样方法和密度、单位及可复现随机种子，必要时双向比较并补关键截面／尺寸。报告“已采样区域的最大／分位偏差”，不称为完整曲面的严格最大误差；窄缝、孔轴和薄边可能被稀疏采样漏掉，须单独检查。

闭合、法向一致、偏差较小等是各自范围的证据，不能合并成“全部可打印”结论。工具报告与实际视图、功能参数及后续切片结果共同交付。

来源：[Trimesh 官方说明](https://github.com/mikedh/trimesh/blob/main/README.md)、[API 文档](https://trimesh.org/trimesh.base.html)、[MIT 许可证](https://github.com/mikedh/trimesh/blob/main/LICENSE.md)。

## 3. CadQuery：可选的精密功能部件支线

仅在明确的功能区域需要 CAD 实体表达、反复参数化修改，且收益足以覆盖新增环境与文件转换成本时提出。简单几何优先沿用 Blender，外观造型继续由既定路线负责；不强制把整个文创产品搬到 CAD，也不将角色网格直接视作可靠的参数化实体。

在建模分工中说明选用部件、尺寸基准、与外观连接边界及交付格式；分工改变时按原规则确认。图纸、分工和所需环境验收后，才由宿主执行实际 CadQuery Python 脚本。其为可独立运行的 CAD 库，不要求有专用 MCP，也不应为运行它而把依赖强行注入 Blender 自带 Python。

将关键尺寸、间隙定义和来源集中为参数；保存实际执行脚本、库版本、参数及 CAD 源输出。STEP 可作几何交换与后续 CAD 参照，但不能替代保留 Python 参数源，通用交换文件不自动携带原参数化过程。修改接口时优先改对应参数并重建该部件，不以整体缩放补偿。

导出网格时显式核对单位、线性／角度细分误差及其绝对或相对含义，按关键曲面与接口选择分辨率；不默认无限加密，也不认为 CAD 源尺寸正确就代表离散网格没有偏差。用当前 Blender 已验证的交换入口导入，检查实际尺寸、轴线、配合面、网格完整性和与外观的过渡，再执行统一验收。STEP 是否可直接导入须核实本机能力，必要时在 CAD 端转换为 Blender 可读网格。CadQuery 导出的几何 3MF 不等同于带 Bambu 工艺和分盘配置的打印工程。

整合、布尔或细化后重新测量关键尺寸和连接区域。需要修改已经精修的结构时，先界定重建范围并保存基准，不能用新生成件覆盖无关人工修改。配合、强度和机构手感仍按原尺寸试样流程验证，CAD 内部实体有效不等于真实产品合格。

来源：[CadQuery 官方项目与 Apache-2.0 许可说明](https://github.com/CadQuery/cadquery)、[导入导出及细分参数](https://cadquery.readthedocs.io/en/latest/importexport.html)、[官方安装说明](https://cadquery.readthedocs.io/en/latest/installation.html)。

具体环境、版本、对象方法冲突、单位、合成验证和回退规则集中见 [Sand3D](sand3d.md)。只辅助当前 Blender 代码任务，不替代精密 CAD、外观或制造验收，也不引入数据集与模型检索。优先复用已验证的函数；原生 bpy 更直接或该函数不适用时沿用原生方式。

## SMLib 多截面曲面

当一个部件的宽度、厚度或圆角沿路径变化，且需用多个截面控制外形与承托面、槽壁等功能面的过渡时，可在建模分工中为该部件选择 NVIDIA SMLib。等截面拉伸、普通圆角、孔槽及规则支架继续用现有 Blender 代码流程，已有合适的参数源也可直接复用。

从已确认的参数图取截面位置、朝向、宽厚和圆角，标出端部边界、应保留的外轮廓以及可随功能尺寸移动的面。统一截面起点与绕向，用官方 `usd-brep` 的 Python 接口放样，再按设计建立功能面。若端部越界或过渡起伏，先定位出错区间，按需调整导向截面，或将直段与弯段分别建模后复验。

保存参数脚本、内核版本、CAD 源和网格细分设置。将实际导出的网格按已知单位导入 Blender，对照图纸检查截面、曲面接缝和功能尺寸。改动槽宽等参数后复测受保护外缘、承托角及相邻剩余厚度，弯钩和爪尖等自由端按 [每次交付前的形体与表面检查](blender.md#每次交付前的形体与表面检查) 验收。

[NVIDIA 官方仓库及许可](https://github.com/NVIDIA-Omniverse/usd-brep) · [官方 Python 包与平台要求](https://pypi.org/project/usd-brep/)
