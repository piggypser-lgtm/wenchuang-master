# 切片参数决策与验证

在打印方案、摆盘与参数配置、切片检查或实物排错时读取；整件和机构试样共用。此文维护“基准 → 目标 → 调整 → 检查 → 实物证据”，操作及成果验收沿用 [Bambu 流程](bambu.md)，不增加独立审批阶段。实际设置在打印方案接受后进行，优先按 [代码配置与切片](slicing-automation.md) 批量准备工程并在 Bambu Studio 核实生效值；配置接受后才切片，切片接受和物理授权满足后才打印。

## 1. 建立本次打印基准

在打印方案阶段只读核对当前工程及设备，不重置已有设置。记录：

- 打印机、喷嘴直径、实际打印板及匹配预设。
- 每种耗材的品牌、具体系列／类型、槽位及材料预设；按问题记录干燥或受潮等状态。“PLA”不是完整的耗材身份，无法确定具体系列时标记未知。
- Bambu Studio 版本，当前设备／耗材／工艺预设名称、可取得的版本或来源，以及用户自定义项。
- 工程对应的模型版本、本轮部件与排除清单（沿用 Bambu 流程记录）、各盘及对象／局部设置，已知校准结果及其适用喷嘴、耗材与设备条件；不把预设名当成已完成校准的证明。

资料顺序：适用的本机有效配置与已验证项目作为基准；官方软件文档解释参数；具体耗材及打印板厂商资料核对适用范围；匹配条件的实测资料辅助调整。配置只是起点，不能覆盖与实物不符的设备或材料信息。来源冲突时查明型号、版本和条件，不能取平均或静默替换。

读取配置文件时，按实际软件的配置机制解析继承、默认值及工程／对象／局部覆盖，保留来源关系；不能把局部 JSON 当成全部生效参数，也不猜测覆盖优先级。必要时与界面或软件导出的配置交叉核对。自动、比例、列表等值保留原单位和对象含义；无法确定解析结果时标记“生效值未核实”，请求相关配置或帮助内容，不宣称已读取完整设置。只提取当前任务所需字段，不扫描凭据。

官方预设目录见 [资源索引 R8](resource-library.md#r8-bambu切片操作与设备排错)。按实际安装版本及配置更新状态查对应内容；仓库 master 仅用于发现，不能不经核对覆盖本机。新增或修改预设保存为当前工程或用户副本，保留原基准及恢复路径。

## 2. 按目标选择检查项

以下是诊断入口，不是自动修改清单。先确定用户最重视的外观、强度、配合、时间或耗材目标，只处理影响当前目标的设置。按 [资源索引](resource-library.md) 和 [参数查证](parameter-research.md) 读取对应原文，不照搬跨机型或跨工艺数值。

| 目标／问题 | 优先检查 | 调整后验证及代价 | 资料入口 |
|---|---|---|---|
| 曲面层阶、外观细节 | 区分几何折面与层阶；方向、层高、局部可变层高及细节路径 | 目标表面、其他面的支撑、细节保留和时间；几何问题返回建模 | R8 软件说明；R1／R2 朝向原理 |
| 支架及功能件承载 | 受力与层向、壁层、局部截面、填充及材料；不默认只增加填充 | 载荷路径、薄弱截面和装配，必要时按明确目标实物验证；记录重量／时间代价 | R1 方向；R2 与实际材料厂商 |
| 榫卯、孔轴配合 | 设计间隙及定义、首层扩张、可用尺寸补偿；有证据时检查流量相关因素 | 接口及无关部位是否一起改变，真实尺寸配合试样；不先用全局缩放修单一接口 | R8 对应设置；R1 配合；实际设备实测 |
| 原位打印或活动结构 | 运动间隙、摆放方向、支撑位置、首层影响及防脱 | 逐层检查间隙有无封闭、支撑能否清理；实物验证活动与保持能力 | R8；R1；所选机构资料 |
| 支撑难拆、接触面粗糙 | 朝向、局部支撑范围、界面及接触距离、支撑材料兼容性 | 必要悬空仍有支撑，拆除路径、外观及接口不受损；少支撑不等于好拆 | R8 支撑文档；R2 设计／材料 |
| 拉丝、翘边、挤出异常 | 按症状核对耗材状态、实际板材与接触、温度、冷却、速度及体积流量限制；必要时查设备故障 | 有明确假设的小范围试验；记录缺陷变化，不同时盲调所有参数 | R8 质量排错；具体耗材／打印板厂商 |
| 容器顶底、薄壁或水密目标 | 层高、线宽、壁与顶底实际路径、接缝及结构连续性；核实花瓶模式是否适用 | 逐层确认未丢壁／缺底；需要水密时单独实测，切片连续不等于不漏水 | R8；R2；产品用途约束 |

参数名称、单位及可用范围以当前软件为准。没有适用依据的数值标为待试验假设并说明范围，不给通用温度、间隙或速度常数。不能为改善表面而隐式改动已接受的功能结构。

## 按部件决定朝向、分盘、参数和支撑

先在打印方案中读取 [本轮零件清单](bambu.md)，按部件或具有相同需求的部件组评估：可见细节与曲面、薄壁／小特征、孔槽与活动接口、承载与层向、悬垂／桥接、底部接触、支撑拆除及工具可达性。结构复杂不自动等于需要密集支撑或全局最细层高；简单外形也可能有精密接口。围绕实际目标选择设置，不能只按颜色或整体尺寸判断。

形成简短的部件方案表：部件／组、精细与功能重点、拟用打印朝向、层高与壁／填充等必要设置、支撑范围／方式、需保护的接触面或间隙、建议打印盘、依据及代价。方案阶段的设置是建议；参数配置阶段记录实际生效值，复用本文件差异表，不新增独立审批。不要把装配或分解展示的姿态当作打印朝向。

先按各件要求再决定能否同盘。核实当前 Bambu Studio 版本中相关设置属于整盘、对象、局部还是耗材范围，支持且适用时使用按对象／局部差异设置；不能假设所有层高、温度、支撑材料等选项都能逐件覆盖。机械小件与大壳体在首层稳定性、冷却、速度或支撑策略上明显不同，或需要先验证高风险小件时，在打印方案阶段主动提出分盘及其时间／材料代价，不等失败后才处理。要求在同盘无法兼容时，优先建议分盘，或说明统一设置的细节、时间与耗材代价后由用户选择。材料相同不强制同盘，也不因部件多就一件一盘；按可用空间、实际兼容性与用户目标决定。

### 支撑方式与接触位置

- **按悬垂形状和拆除路径选型。** 先判断调整朝向或利用已有验证的桥接能力能否可靠成形。确需支撑时，大面积连续悬垂可优先评估普通支撑，分散的小悬垂或需要绕开细节的曲面可评估树状支撑。按需要限定为仅从热床生成，或用手涂指定、屏蔽局部接触。即使沿用默认预设，也要在部件方案中说明它能托住哪一面、工具从哪里进入、支撑如何脱离并取出。
- **精密与脆弱部位优先避开直接接触。** 标出精密配合面、细齿、细轴、薄壁、卡扣和弹片等需保护的区域。优先调整朝向或把接触点移到可触及的厚实非配合面，避免支撑包住细件、堵住孔槽或活动间隙，也避免拆撑时借细件作支点、将其连带折断或误剪。选用树状支撑时，也应核对保护区附近的分支走向和实际接触点。
- **必要承托与可拆性须同时满足。** 若关键悬垂只能在精细部位附近承托，保留足以成形的局部支撑，按材料和几何选择接触范围、支撑界面及间距，并明确拆除顺序与受力位置。若找不到可达且能保护零件的拆除路径，返回朝向或经确认的分件／结构调整。对确有损伤风险且缺少实测依据的部位，可用保留实际层向和支撑条件的局部原尺寸小样验证。

配置接受后才切片，检查范围、首层优先顺序与结束条件统一按 [切片检查](bambu.md#切片检查) 执行，必要时用关键区域试样验证。以实际切片结果报告耗时、耗材及各方案代价，分盘后核对每盘清单与材料映射；不预先把全盘时间分摊值当成逐件实测。

## 3. 展示参数差异，沿用既有验收

打印方案说明基准、目标、拟比较方法和主要代价，不提前切片获得估计。摆盘与配置阶段展示实际已设置的修改项：

| 参数／对象／作用范围 | 修改前生效值 | 当前建议／设置值 | 依据与来源编号 | 代价／待验证项 |
|---|---|---|---|---|

依据分别标记“官方预设／厂家建议”“匹配条件的实测结果”“待验证假设”。未核实旧值不得编造；采用继承值时说明实际解析结果。设置后核对是否真正生效以及作用于哪些盘、对象、材料或局部区域；预设名称相同不代表值相同。程序化流程须核对 GUI 实际载入与实际切片后的生效值；完整另存回读只在首次接入、相关条件变化或异常触发时按执行文档进行，按 [输出核验](slicing-automation.md#41-核对实际输出与参数差异) 处理意外改写与统计异常。自动比较可取得的配置，面向用户只展开计划修改、非预期差异和未验证项；无变化的参数保存在可复查工程中，不逐项讲解。

配置成果展示后，按原选项确认规则等待接受，再切片。切片阶段用实际预览、耗时与耗材评估方案；此前的时间／耗材只能明确标为估计。若已授权比较多个配置候选，逐一记录对应切片；超出认可范围的方案先确认。切片检查发现问题时，按 [Bambu 失败恢复](bambu.md) 在当前授权范围修复重切；改变设计或比较范围则返回相关确认，不能无声扩展。

## 4. 试验、归因与经验回用

配合、回弹、手感、水密和支撑接触效果无法由预览确定时，使用 [机构试样分支](modeling-plan.md) 或既有整件试打计划。说明验证目标、可观察判据、涉及参数及返回节点。每轮尽量只改变待验证因素；确需联动的参数作为一组记录并说明原因，不能把结果归功于某一个未被单独验证的参数。

保存实际采用值及偏离计划的情况；资料建议、切片预测和实物观测分别记录。失败时先判断来源是几何、材料状态、方向、配置还是设备，只修改有证据关联的部分。没有改善则回到可复查基准并重新诊断，不无限试调。试验次数和费用沿用用户已接受范围。

按 [项目记录](project-record.md) 关联模型版本、3MF 工程、有效配置、来源、试样和实物反馈。记录适用的设备／喷嘴／材料／板材／方向／结构；以后条件相符才复用。改变其中相关条件后重新评估受影响结论；一次成功不证明长期耐久，也不自动推广到不同接口。项目经验留在项目内，公开 skill 只保留通用方法、来源索引和原创总结。
