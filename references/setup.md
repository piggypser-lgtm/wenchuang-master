# 环境与项目配置

本技能包包含工作流程、参考说明、发布检查工具和标准库实现的离线 Bambu 项目适配脚本，不捆绑 Blender、Tripo 客户端或插件、MCP 服务、Bambu Studio 或打印机驱动。依赖在使用者自己的环境中发现，缺失时按下述流程经同意协助安装；不需要作者的其他技能、项目文件或聊天记录。其他专业技能可以按需辅助，但不是必须依赖。

## 运行前发现能力

- 参数查证：使用 Web Access 的搜索与原文读取能力；已提供 web-access 技能时加载并遵循它。缺少该技能时使用宿主等价能力并说明，完全离线时标明未核实项。详见 [设计参数查证](parameter-research.md)。

- 设计阶段：宿主能读取用户图片，制作并展示多视图图像或足以表达形体的二维图纸，创建项目文件并与用户分阶段沟通。只有文字生成能力不足以完成多视图展示。

- 实际建模：宿主连接到 Blender MCP，具备场景读取、代码执行及可检查的截图/渲染能力。工具名称和命名空间不固定，按能力发现并只读测试；本技能不绑定特定供应商或服务地址。

- 按需几何检查与 CAD：按 [建模工具](modeling-tools.md) 发现 3D Print Toolbox 的版本、启用状态和报告读取能力，Trimesh 的项目运行环境与所需分析能力，以及已选 CAD 工具的执行、网格导出与 Blender 接收能力。只检查当前分工需要的组件。

- 可选代码封装：按 [Sand3D 几何函数库](sand3d.md) 核实当前 Blender Python 的模块发现、版本、同名对象方法冲突和已验证操作；复用现有 bpy 与 MCP，不将安装数据集或新 MCP 作为条件。

- 可选参数化／分节生成：按 [建模计划](modeling-plan.md) 发现所选 MakerLab、Flexi 或本地 OpenSCAD 等入口，核实版本、依赖库、账户、输入输出和 Blender 接收能力；不将全部工具设为必装项，具体接收见 [参数化接入](parametric-structures.md)。

- 所选混合路线的生成式建模：发现 Tripo 的宿主插件、MCP、CLI 或 Blender 端插件，核实实际输入、任务查询、下载及导入能力；单图入口不默认支持多视图。缺失时经用户选择路线和确认安装方案后补齐，详见 [Tripo 流程](tripo.md)。

- 切片阶段：安装 Bambu Studio，按 [代码配置与切片](slicing-automation.md) 优先发现完整配置读写、工程导出和本机命令行／程序化切片能力，保留界面载入核验、特殊处理及预览能力；不支持的步骤用界面或人工交接。离线配置／切片无需设备在线，设备发送单独核验。

- 实际打印：目标设备在线、打印配置匹配，控制通道支持发送且本次操作已获授权。

通过当前用户配置、宿主工具发现、系统应用信息或明确指定的路径定位软件。不要遍历所有磁盘寻找凭据，不假定操作系统、盘符或固定端口。软件已安装、进程存在、工具已注册、连接成功、操作已验证是不同状态，分别记录。

本包提供 [Bambu 项目适配器](bambu-adapter.md)：读取比较、已验证结构的定向参数修改、打开软件、限定版本的离线切片及查看副本生成；它不控制界面、不连接打印机、不发送打印，也没有跨平台端到端实测承诺。缺少能力时说明具体缺口，仅继续当前任务内可独立完成的步骤，不跨过成果验收；在适用阶段给出明确人工交接或适配器接入方案。不得把人工操作写成自动执行成功。

## Blender 与基础插件的检查、安装和验收

进入建模任务前执行以下检查；可行性阶段只读发现环境不代表可以提前建模或安装软件。

1. **核实已有环境。** 检查操作系统、架构、用户安装位置偏好、Blender 路径与版本、是否能启动；分别检查 MCP 工具注册及连接、所选实现需要的 Blender 端组件和宿主端服务、Bool Tool 等基础插件的安装及启用状态。工具未出现不等于 Blender 未安装；优先修复路径、启用或连接，不擅自卸载、升级或重复安装可用版本。
2. **准备具体安装方案。** 缺少 Blender、MCP 或基础插件时，通过 Web Access 查阅缺失组件的官方安装说明，核对 Blender 官方下载资料、所选 MCP 官方维护仓库及插件官方目录/文档的当前兼容要求；提供适合本机的版本、来源链接、安装位置、下载和依赖占用估计、需变更的宿主配置及重启事项。遵守用户的存储偏好，下载、缓存和依赖也使用相应位置，不硬编码作者路径或固定版本。无法查证兼容性时说明缺口，不猜测包名或执行命令。
3. **先询问，再安装。** 按交互规则提供“按此方案安装并配置”“我自行安装后再检查”“暂不安装，停留在当前阶段”等选项，等待实际答复。安装方案应同时列明 Blender、所选 Blender MCP 及适用的 Bool Tool 等基础组件；用户同意这一范围后连续完成其安装配置，无需每个步骤重复询问。Blender 已有但缺 MCP 或插件时，仅就缺失项提出方案；既有明确授权覆盖同一范围时直接沿用，不因一般建模授权就默认获准安装软件。
4. **配置必要组件。** 按已核实文档安装 Blender，以及所选 MCP 实际需要的 Blender 端组件、宿主端服务和依赖，配置并启动本地连接；不把仅安装其中一端当作完成。核对当前版本的 Bool Tool 是已提供但未启用，还是需要从适用的扩展渠道安装，再启用并验证。其他基础插件只选择当前任务有明确用途、来源可信且兼容的少量项目，并列入同意的方案，不批量安装插件集合。保留已有用户配置；需要重启前先保存工作并说明影响。
5. **核验与交接。** 验证 Blender 能启动、MCP 能读取场景并执行无修改的查询、截图能力正常；核实已安装基础插件可用。涉及产品或其接口的测试几何，须在相关设计图和建模分工已验收后进行；只验证工具本身且已明确授权的独立合成测试，按下节边界执行。两者都使用独立临时场景，不触碰无关产品文件，环境测试不能充当草模或设计图。记录通过、失败及未验证项，向用户展示环境检查结果并提供进入建模或继续修复的选项；产品建模仍须满足设计图验收前置条件。

缺少安装权限、网络或自动化能力时，说明具体卡点并给出最少的人工操作，用户完成后重新检查；不虚报已安装、已连接。插件不兼容时提供可用原生操作或兼容方案供选择，不能因辅助插件缺失就默默跳过用户要求，也不能把全部可选插件作为建模的硬性前置条件。本技能规定安装协助流程，不随包分发第三方程序或保证任意宿主都能自动安装。

## 独立工具兼容性验证

用户明确要求安装并验证工具本身时，可用独立、简单、不含用户产品造型或真实配合接口的合成试件检查函数、尺寸、几何、导出与连接。它不要求先制作产品设计图，也不新增产品验收节点；一般产品建模授权不能借此绕过图纸或阶段确认。保留原场景和未保存状态，测试产物放入独立目录，分别报告受测范围、失败与未验证项。实际产品、接口试配和制造样件仍按原设计及试样流程执行。

## 按需几何检查与 CAD 环境

选用 [3D Print Toolbox、Trimesh、CadQuery、SMLib 或 Sand3D](modeling-tools.md) 后先检查现有可用组件。新增组件沿用上文的具体方案、明确确认、安装和能力核验流程；只补本次所需项，不因公开 skill 列出工具就默认获准安装。方案说明版本、来源、操作系统／Python／Blender 兼容性、运行环境及下载／缓存位置，不硬编码作者环境。

- 3D Print Toolbox：区分已安装、已启用、检查可运行、报告可读取。优先使用适用 Blender 版本的扩展来源；当前无法兼容时可用已验证的原生检查，不擅自更换用户 Blender。
- Trimesh：核实独立项目 Python、库版本和本次检查所需的可选依赖；不为少量几何核验默认安装全部依赖或新的 MCP。只读查询可检查库是否导入，真实文件分析仍在当前检查任务内进行。
- Sand3D：按 [函数库接入](sand3d.md) 核对 Blender 自带 Python，优先仅补所需库并注册可发现路径，避免重复安装 bpy。运行中的 Blender 可能尚未读取新增路径，须单独核验当前会话和重启后的发现；不为加载辅助库强制关闭未保存工程。
- SMLib 选用后，按 [官方 Python 包](https://pypi.org/project/usd-brep/) 核对目标平台、Python 版本和可用发行包，优先复用兼容的独立环境。缺少依赖时按上述安装确认流程处理，核验所需放样、网格转换和 Blender 接收能力。
- CadQuery：仅在功能分工已选时核实对应 Python、CAD 内核依赖和导出能力，优先使用独立环境，不向 Blender 自带 Python 强装依赖。安装完成不等于生成及 Blender 接收已验证；涉及产品／接口的隔离几何测试仍须满足原有图纸／路线前置条件；独立合成工具测试仅适用上文的明确授权边界。

图纸已验收且进入相应任务后，分别报告检查／生成执行、报告读取、导出回读及 Blender 接收的实际状态；没有运行的部分标为未验证。依赖不足仅回退受影响步骤，不改变已接受的造型、用途或精度目标。

## Tripo 组件的检查、安装和验收

进入建模流程时沿用 [协同建模](hybrid-modeling.md) 已确认的路线。简单形体或已选直接代码路线只核验所需 Blender 能力，跳过 Tripo 接入、账户及余额检查。选择混合路线时，除 Blender 外按以下步骤核验 Tripo：

1. **选择最少的必要组件。** 优先复用已连接且能力足够的工具。缺少接入时核实官方宿主插件是否可安装；不可用时可选官方 CLI 加宿主调用或兼容 MCP，模型由现有 Blender MCP 导入。用户需要 Blender 内操作时再评估适用的 Tripo Blender 插件。不要同时安装多个实现同一能力的桥接插件，也不因同属 Tripo 就假定版本、账户区域和功能兼容。
2. **查证并展示安装方案。** 通过 Web Access 读取 [官方 CLI 说明](https://developers.tripo3d.ai/en/docs/cli) 与 [官方插件目录](https://developers.tripo3d.com/zh/docs/plugins)，核实所选组件及其运行时、包管理器、依赖、API 版本和操作系统/Blender 兼容性。说明官方来源、版本、安装和缓存位置、预计占用、宿主注册及重启影响。现有环境已满足时不升级或重装；旧插件不兼容时提出替代，不盲目覆盖已启用组件。遵守用户存储偏好，先安排下载、临时文件、依赖缓存和账户配置目录，再安装。
3. **按选项确认后执行。** 展示“按此方案安装并配置 Tripo”“我自行安装后再检查”“暂不继续”等选项；只有按 [可行性判断](feasibility.md) 确认适合当前目标时，才提供“改用 Blender 直接建模”。否则按缺口提供补齐条件、人工生成后导入或调整方案，不能将未安装 Tripo 等同于全代码可行。等待明确选择，路线改变须更新受影响分工及设计。获得同一具体安装方案授权后完成必要下载、运行时/插件安装、启用、注册与连通检查，无需逐条命令重复确认。新增依赖、替换可用组件或其他超出方案的实质变更先重新说明并确认；常规建模授权和方法选择的默认等待规则不能替代安装确认。
4. **账户连接。** 沿用已确认地区；未知时询问中国站或国际站，不按语言猜测。优先使用官方浏览器授权，让用户自行登录并确认验证码；无需用户把 API 密钥发进聊天，也不读取、打印或复制密钥。需要密钥的入口使用工具支持的安全配置方式。凭据保留在使用者本机安全配置中，绝不写入本 skill、项目共享记录或发布包。
5. **只读验证并交接。** 检查组件版本、认证、所选地区的 API 可达性、工具发现及余额，并核实 Blender 的导入能力。余额为零不代表安装失败。分别报告已安装、已启用、已连接、导入未测试、生成未测试等实际状态；展示结果，提供进入生成计划或继续修复的选项。环境检查不提交付费生成、不上传用户图片；测试生成也须按 [Tripo 流程](tripo.md) 展示具体计划并确认。

安装权限、联网或自动调用能力不足时，给出准确官方来源和最少的人工步骤，完成后复查。可采用“用户在网站生成，助手导入 Blender”的交接路线，但先确认该分工；不能把下载包当作已启用插件，或把工具已注册当作端到端生成成功。

## 参数化与分节工具的环境交接

按已接受分工检查所选平台及库；资料阅读阶段无需安装软件。在线入口核实当前地区功能与账户状态，本地入口核实 OpenSCAD 等运行时、库版本和实际导出；需要新组件时沿用上文“具体方案→明确确认→安装配置→只读核验→结果验收”的流程。按用户偏好安排下载、临时目录和缓存，已有环境不重复配置。

连接成功、源文件可加载、生成可执行、导出可读、Blender 导入通过是不同状态；未测部分如实说明。只读核验不上传素材或提交付费生成。涉及产品／接口的隔离几何测试须在图纸与分工验收后进行；另行明确授权的独立合成工具测试按上文边界执行，不能据此开始尚未验收的产品任务；生成前确认和候选交接见 [参数化接入](parametric-structures.md)。

## 项目配置

配置是可选的；用户在对话中提供等价信息时直接使用。需要持久化时，将 [空白配置模板](../assets/project-config.example.json) 复制到项目根目录，命名为 photo-to-print.local.json。由执行技能的助手读取解释，模板不是自动配置软件的程序。

配置优先级：用户本次明确指示 > 当前项目配置 > 用户已确认的个人偏好 > 明确标注的临时建议。软件实际状态与配置冲突时先核对，不静默切换设备。null 表示尚未确认，不代表禁用或自动选择。

- output_dir：相对项目根目录的输出子目录。不得以技能安装目录为项目输出目录。

- blender.executable_path、bambu_studio.executable_path：可选的运行时路径；为空则发现安装位置。用户路径只留在本地配置。

- bambu_studio.control_method：经验证的控制方式说明；为空表示未确定。

- printer：设备型号、喷嘴直径、材料、打印板、材料预设及多色配置，按实际用途填写。

相对配置路径均以项目根目录解析，执行前规范化并检查输出仍在项目范围内；若要写到项目外，先以用户指定的新项目根目录建立范围。不得从项目名或不可信文件名拼接可逃逸的路径。跨平台使用路径库，不拼接操作系统专有分隔符。

配置中不保存访问码、令牌、设备序列号或账号密码；这些由宿主的安全凭据机制提供。本包 .gitignore 排除个人配置和运行结果，但外部项目要自行设置相同规则。分享配置时使用空白模板。

## 能力交接结果

项目记录只记经过验证的能力，例如“场景读取通过”“工程参数回读通过”“界面载入未验证”“指定盘切片通过”“设备发送不可用”。CLI 帮助无输出或退出码为零不能当作验证通过；软件版本、预设来源、已验证字段／范围及小范围试验结果分别记录，配置准备与切片验证仍遵守其前置验收。运行记录不写回技能包。更换设备、软件版本或控制方式后重新检查相关能力。
