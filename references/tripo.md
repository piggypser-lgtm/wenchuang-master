# Tripo 生成与 Blender 功能化建模

Tripo 为默认混合路线生成外观基础，Blender 代码构建精确功能结构；先按 [协同建模](hybrid-modeling.md) 判断直接代码建模是否更适合，简单形体无需 Tripo。采用混合路线后，按 [环境配置](setup.md) 检查并经确认安装必要组件。Blender MCP 负责接收、精确结构建模、修形与打印验证。主体按 [可行性判断](feasibility.md) 评估所选路线；复杂外观不因难以代码还原而直接拒绝，但生成式补全不能充当原实物结构证据，关键结构看不清时优先补对应实拍。进入设计只代表路线有依据，实际候选仍需在 Blender 验证可保留外观、可建立功能区及可整合空间。

## 入口与阶段顺序

阶段前置与推进顺序统一按 [主流程](../WORKFLOW.md)，不得跳过图纸、分工、环境和各独立成果验收。本文件只展开已选 Tripo 路线的输入准备、生成计划、候选接收／重新生成及回到 Blender 的交接；派生图的先主视图后其他视图规则见 [多视图设计](multiview-design.md)。需要先验证机构时按 [建模计划](modeling-plan.md) 插入试样并明确返回节点，不要求先付费生成外观。

选择 Blender 直接建模时跳过 Tripo 专属步骤。已提供外部模型时先核实来源、版本和使用范围，再检查接收；不能把外部模型本身当作设计图已确认。Tripo 候选验收只接受外观基础，不等于功能草模或最终产品验收。用户明确选择某个候选继续功能建模后，无需再重复确认同一候选。

## 生成前准备与确认

- 以已接受的完整设计为最终依据；选定去部位路线时，实际输入使用按 [派生图流程](multiview-design.md) 分别验收的主体生成图。原图片只补充已确认特征，不覆盖设计改造。记录实际上传文件、版本及省略清单；尺寸标注、箭头、背景道具、配合物和结构占位不混入生成图。无标注清理可在当前输入任务内处理，几何外观删改不能伪装成清理；派生主视图未接受不制作其他派生视图，整套未接受不开始生成计划或任务。

- 按当前模型与调用入口支持的输入方式传递图片。多视图须分别对应正确方向、同一主体及一致造型，核实必需视角、数量和格式；单图工具不代表支持多图，不把拼图等同于原生多视图，也不把侧面主视图冒充正面。缺少视图时说明并补图验收，或由用户选择单图方案。

- 读取实际工具参数或已安装 CLI 文档，再按需核实官方文档。宿主有可用的 Tripo 专业技能时按需使用；本包不依赖作者安装路径或固定工具名称。不同插件、CLI、MCP 的功能与默认值分别核验，不能把一个入口的参数直接套给另一个。

- 使用可用的计划工具（例如 tripo_plan）或 CLI 的 dry-run，列出本轮每个步骤、模型版本、质量/面数意图、纹理选项、输出格式、素材上传范围、预计积分及总预算。明确估算与实际扣费的区别；工具不给金额时先查当前计费依据，无法确定则说明并请用户决定预算，不擅自开始。打印任务优先关注几何，纹理不能替代实体细节；“print”预设中的自动切底、格式转换等操作也须检查，不允许预设悄悄改变设计。

- 展示计划后提供“按此计划上传并生成”“调整设置或预算”“暂不生成”等选项，等待明确确认。只有已评估适合当前目标时才增加“改用 Blender 直接建模”；否则说明补齐条件、人工生成后导入或调整方案等适用选择，路线变更须明确接受。已有明确授权仅覆盖列出的输入、步骤、次数与预算；安装、登录、选择路线或余额充足均不等于生成授权。额外后处理、批量候选或重新生成超出已确认计划时重新确认。

## 分部件生成任务

按 [协同建模](hybrid-modeling.md) 可分别生成主体和局部外观，输入准备及验收复用 [局部图规则](multiview-design.md)。计划逐部件列明输入、左右与朝向、连接端、候选及预算，不因改一个部位就默认整机再生成。各候选按自身范围在 Blender 展示验收；批量生成授权不合并各部件成果接受，进入接口制作和整合前须接受所用候选。精确接口交由代码，整合后另按完整产品设计核对比例、朝向、根部过渡与运动空间。

## 任务执行与恢复

提交一次后保存任务编号、模型及输入版本。按[工具内等待](slicing-automation.md#在工具内等待已有任务)使用已有任务的完成通知或等待接口。仅支持查询时，在工具内按服务建议间隔和速率限制有界查询同一编号；仅在有结果、失败、需用户决定或时限到达时回报。超时或提交状态不明时，先查已有编号、历史和额度占用；新增付费生成须按原计划授权。

任务成功后下载实际模型到当前项目，并保留原始输出及任务元数据。下载链接过期时重新查询已有任务，不为重新下载再次付费生成。报告实际积分及各步骤明细，缺少扣费数据时标记未知，不能凭余额差猜测。登录失败、额度不足或控制不可用时说明状态，并提供补齐条件、人工生成后导入、或经可行性评估适用的 Blender 直接建模选项，不擅自购买积分或切换账户；工具暂不可用不等于外观目标不可行，全代码也不是默认可用的兜底。

## 接收模型与外观验收

通过 Blender MCP 导入项目专属集合，保留原始生成文件和独立工作副本，复核格式、单位、坐标方向和实际包围盒。先作接收检查、必要定向与比例校准以及预览；若高面数已妨碍检查或后续操作，按 [拓扑优化](blender.md#高面数导致低效时的拓扑优化) 在当前接收任务内作必要保形处理，不将其变成强制预处理。候选尚未验收时不开始功能结构或正式细化。

对照实际输入的完整／派生图及拆分清单，以匹配视角检查轮廓、比例、姿态、部件数量及关键负空间；按 [候选接受范围](hybrid-modeling.md#候选的接受范围) 展示保留区、计划替换区和阻塞问题。有意省略不算缺件，须标明补回路线；评估连接区域、剩余厚度及可用功能空间，不在候选未接受时建立功能结构。用中性材质和低分辨率多角度预览检查实际几何，并按 [视觉特征的制造交接](hybrid-modeling.md#视觉特征的制造交接) 对照贴图核对必留特征。阻塞问题留在当前任务；仅供讨论修复路线的候选不标记通过。

展示 Blender 中的实际结果、接受范围及剩余偏差，明确提供“接受这一版，进入代码功能草模”“保留这一版，再生成一版比较”“调整输入或要求后重新生成”“在 Blender 中局部修改”“改用代码重建相关部位”等适用选项；项数超出交互工具容量时使用完整编号列表，不隐藏重新生成入口。存在阻塞问题时将继续选项改为对应修复或补充方案，不能允许直接越过。局部外观修复或外观部位代码重建留在当前候选任务，修改后重新展示验收。功能部位重建须先明确接受保留外观及已展示的替换方案，再进入功能草模；点击选项不自动接受未展示的方案，也不代表功能已通过。大改先修订设计图。连续无法达到已确认造型时停止无效重试，说明限制与可行替代。

## 候选保留、比较与重新生成

“再来一版／抽卡”是当前候选阶段的正式分支，不表示当前模型已获接受。保留每次候选的原始输出、任务编号、输入版本、设置及已知费用；新结果不覆盖旧候选，不自动成为选定版本。保持相同视角和尺度展示 Blender 中的比较，说明外观偏差、几何缺陷及预计结构改造难度；用户明确选择后才进入对应下一阶段。

同输入再次生成仍是一次新任务：核对已确认计划中的剩余次数、步骤及预算，用户明确选择且处于该范围内可沿用授权；范围未涵盖、费用未知或输入改变时先展示修订计划并确认。用户要求的多候选比较可按已确认批次数执行，单次“再来一版”不授权无限循环。失败、超时与下载恢复按任务执行规则，不能把技术重试当成免费抽卡。

仅精密孔槽、接触面或局部角度不合适时，主动推荐代码调整／重建方案，同时保留用户选择重新生成的权利。更改派生输入须重新验收受影响派生图；影响最终造型时还须修订完整图。预算／次数用尽或连续不能改善时停止提交，展示现有候选与可行替代，由用户决定下一步。

## 已有功能结构后更换外观候选

功能草模或细化已有成果时仍可重新生成全部或局部外观；先区分“仅比较候选”和“选用新候选替换”。原生成件、已接受整合版本、结构源及人工修形检查点继续保留，新任务或比较本身不使旧成果自动失效，也不覆盖当前基准。

- 在已有分工／修改方案节点，展示本次替换范围、保留结构、真实尺度与连接基准、保护区、受影响的图纸和验收，以及整合后返回的具体节点，取得明确接受；同范围已接受方案直接沿用。造型变更先修订受影响设计，再按本文件确认输入、生成计划、费用和新候选，不合并这些验收。
- 新候选接受后才在副本重新配准并整合；保留机械硬参数，不以缩放接口或配合物迁就新外观。逐项核对依赖旧网格的布尔对象、贴合目标、顶点／面索引、选择集及局部绑定是否仍适用，失效项定向重建，不能直接套用旧操作或覆盖未改部件。
- 整合后检查连接根部、厚度、外观过渡、运动／装配空间及保护区。受影响的草模或细化成果重新展示并按选项验收；未改变且依赖条件未变的独立部件沿用原确认。新外观改变载荷、根部或打印条件时按 [机构复用与验证范围](mechanism-reuse.md) 复核相关试样结论，不自动要求全部重做；受影响导出、工程和旧切片按现有版本规则失效。

## Blender 完成功能与打印几何

候选接受后，按 [Blender 执行](blender.md) 建立真实尺寸的功能草模：承托面、容器内腔、壁厚、轴孔、磁铁槽、榫卯及配合间隙由明确参数建立或重做，并使用独立真实尺寸配合物验证。不得依据生成网格中的近似孔槽宣称适配。按 [协同建模](hybrid-modeling.md) 对严格功能区选择局部变换、接触面重建或整部位代码重建；参数偏差在草模阶段处理，不等到细化时反复试修。省略部位按拆分清单恢复，整合后对照完整产品图验收。草模展示并获确认后再细化；外观还原、局部保护、高面数优化及低分辨率预览规则继续适用。

自动分割部件不等于可装配打印件，须另做连接和路径检查；三角面或四边面本身不证明可打印。纹理色彩不是多色打印配置，STL 导出成功也不证明实体完整。生成结果仍需经过几何、导出、切片与实物验证。
