# Sand3D：可选的 Blender 几何函数库

在 Blender 代码建模中，需要简化重复的拉伸、孔槽、布尔、倒角和定位操作时读取本页。Sand3D 是对 Blender Python 几何操作的封装，实际输出仍为 Blender 网格；它不替代 [协同建模](hybrid-modeling.md) 的分工、[Blender 验收](blender.md) 或精密 CAD 支线。本分支只采用几何函数，不引入数据集下载、模型检索、关节系统或新的生成路线，也不设为所有项目必装项。

| 当前操作 | 可按实际版本评估的函数 |
|---|---|
| 轮廓与拉伸 | rect、poly、extrude |
| 孔与槽 | hole、pocket |
| 布尔组合 | cut、join、intersect |
| 圆角与倒角 | fillet、chamfer |
| 定位与重复 | at、transform、bbox、grid |

签名、坐标基准和对象消耗规则以当前 [官方 API](https://github.com/Sandflow-ai/sand3d/blob/main/docs/api.md) 为准，不把本表当完整调用文档。生成几何继续通过已有 Blender MCP 执行，结果在同一建模流程中检查、修改和展示，无需为本库另设 MCP 服务。

## 适用范围与收益边界

对常规机械结构中的轮廓拉伸、规则孔槽、布尔、圆角与定位等重复操作，可评估 Sand3D 以简化代码编写和维护。已有原生 Blender 复用函数，或原生方式更适合当前局部修改时，继续沿用原生方式；不为使用函数库重写已经有效的建模流程。

代码更短不代表几何运算更快，也不保证整个任务的耗时或 token 消耗减少。需要量化收益时，在相同尺寸、功能要求、曲线细分精度与验收条件下比较；分别报告源码规模、实际生成调用的输入／输出 token，以及代码生成、依赖加载和几何执行耗时。说明测量范围与次数，不将源码 token 的减少率当作整个流程的节省率，也不将单个零件的结果推广为所有模型的承诺；不为每个产品强制增加性能测试。

## 环境与安装

先读取宿主 Blender 版本、内置 Python 版本、Sand3D 是否可找到及已加载版本，再对照 [依赖声明](https://github.com/Sandflow-ai/sand3d/blob/main/pyproject.toml) 核实兼容条件。系统 Python 可导入不代表 Blender 内可导入；未列入官方支持范围时标为未验证，不推断必然兼容或不兼容。

按 [环境配置](setup.md) 展示所需版本、来源、路径及影响，获得明确授权后安装；同一范围已有授权直接沿用。已有 Blender 的 bpy、bmesh 和 mathutils 优先复用，其余核心代码使用 Python 标准库，不因普通安装命令的依赖解析额外下载另一套 bpy。采用独立包目录或宿主适用的模块发现方式，让当前 Blender Python 找到经过核实的完整库；下载、缓存、实体目录与必要发现配置遵守当前用户的存储偏好，不写死盘符、用户名或版本。它是 Python 库，不要求当作附加组件注册；不为此替换现有 Blender、安装数据集或增加 MCP。

## 导入与现有工程保护

导入前核对 [frames 实现](https://github.com/Sandflow-ai/sand3d/blob/main/src/sand3d/frames.py)：已查版本会给 bpy.types.Object 增加或覆盖 face、edge、move、turn、offset 方法，并注册退出清理。区分本库已经加载的绑定与其他工具同名扩展；有冲突时采用隔离进程或回退原生 bpy，不覆盖第三方方法。不能把 import 描述为完全无副作用的只读查询。

import 本身不清场，但 [empty_scene 实现](https://github.com/Sandflow-ai/sand3d/blob/main/src/sand3d/assembly.py) 会恢复空白场景。不得在现有用户工程调用 empty_scene，也不照抄示例的清场段。保护当前文件、未保存操作和无关对象，在项目专属集合或隔离副本中工作；布尔会消耗工具对象时，按实际 API 保留必要源对象和检查点。

## 小范围验证与采用条件

优先验证本次确需的函数：以独立的简单试件检查拉伸尺寸、孔槽贯通与位置、布尔结果、倒角实际尺寸及定位变换，并读取几何结果；导入成功不代表全部函数或当前版本兼容。几何检查通过、导出回读通过与 MCP 实际调用通过分别报告，后台测试不能冒充已接通当前用户场景。

用户明确要求安装并验证工具本身时，可在独立临时工程做不含用户产品、图纸或原有模型的合成几何测试；这种工具兼容性测试不要求先为产品制作设计图，也不增加产品验收阶段。安装授权未包含创建测试几何时先补足该范围。该例外不能用于提前建立产品草模、试配件或本项目接口；实际产品建模仍须满足 [主流程](../WORKFLOW.md) 的图纸、路线及环境前置条件。

失败时记录宿主／库版本、受测操作和具体错误，保留干净检查点；仅对受影响操作回退已验证的原生 bpy，不为了保留辅助库反复破坏模型或擅自改变产品方案。变更宿主、库或关键操作后重验受影响能力；一次测试不宣称跨版本、所有模型或打印兼容。

## 单位、尺寸与导出

在首个几何操作前明确程序单位，并与当前 Blender 场景的单位尺度、对象坐标和目标毫米尺寸核对。仅把界面显示改成毫米不会同步网格坐标，Sand3D 也不会自动替已有工程调整长度基准；沿用原工程单位，必要时只对本次新建几何作明确换算并复核，不擅改场景单位或缩放已有对象。已查实现默认以毫米写参数，而其 export 会将包括 STL 在内的输出换算成米；采用时复核实际版本的 [导出源码](https://github.com/Sandflow-ai/sand3d/blob/main/src/sand3d/meshfile.py)。不能因代码写了毫米，就假定切片软件会按同样尺度解释文件。

优先沿用当前 Blender 中已经验证的受控打印导出路径，明确选择对象、坐标、缩放和目标单位；重新读取导出文件，以已知尺寸核对，之后在 Bambu 中复核实际尺寸。确需使用本库导出时，对其单位转换作专门验证，不自动重复缩放，也不以整体缩放配合物补救接口错误。

保存实际执行脚本、关键参数与来源、库版本或源码指纹，并测量实际网格尺寸。代码参数可改不代表关联完整；改孔距、厚度或整体尺度后检查相邻尺寸和接口，不能仅凭参数值或函数返回成功验收。

## 保留原有几何与制造检查

Sand3D 使用离散网格；圆弧分段、布尔求解和圆角钳制都可能使实际结果与输入意图不同。当前 [编辑实现](https://github.com/Sandflow-ai/sand3d/blob/main/src/sand3d/edit.py) 的 fillet 在空间不足时可能缩小半径，布尔成功也不保证无开放边。核对关键圆角、孔槽与接触面，保留 [Blender 检查](blender.md) 中的形体、非流形、薄壁、保护区和导出检查；精密 CAD 需求继续按 [建模工具](modeling-tools.md) 选择适用方法。

无论采用 Sand3D 还是原生代码，建模后都须在 Blender 中检查实际几何并按需修改，再按现有成果确认规则展示验收。孔槽除位置和名义尺寸外，还应按功能截面与装配路径检查最小有效净空；不能仅用圆周顶点间距、包围盒或两个正交方向的直径代替。按功能公差选择曲线细分精度，圆角、布尔和其他影响接口的操作后重新测量；发现偏差时在受影响区域调整分辨率或建模方法并复验。尺寸补偿或接口改变仍按原设计确认规则处理，不以整体缩放替代配合修正。网格检查通过仍不等同于实物装配或打印通过。

机械结构及零件始终遵守 [可打印性与支撑易拆性](design-rules.md#代码建模中的可打印性与支撑易拆性)，按真实打印方向检查支撑接触与取出空间，不能因函数生成成功而省略。涉及外观、接口或拆件取舍时沿用现有确认规则；实际切片与试打保持各自前置验收。
