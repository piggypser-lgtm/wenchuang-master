# 成熟机构复用与按改动验证

适用：机械、可动、弹性卡扣或依赖配合的功能结构。先读 [机构卡片](mechanism-library.md) 中与当前动作相关的条目；不要求每次遍历全部库。卡片是已核对许可与作者实物记录的候选，不是本项目的合格证明。

## 先选成熟核心，再适配外围

在用途／机构方案阶段，优先筛选功能、尺度、材料工艺、运动空间及维护方式相符的既有方案。采用顺序为：有适用实物证据的开放设计 → 对其外围接口做最小适配 → 缺少适配方案时定向查找、比较可直接安装的标准成品或自行设计。已有明确方案直接沿用评估；不为套库改掉用户要求，也不强制先造一个全新方案来比较。

默认展示 2–3 个实际合适的候选；只有一个时说明，不凑数。每个候选简述：动作与用途、打印件和外购件数量（未知单列）、来源许可、证据覆盖什么、需改哪里及预计验证范围。与 [最少零件原则](design-rules.md) 同时应用：满足功能、可靠性、可打印性和维护要求后比较实际总件数；未经验证的减件设想不能直接视为同等可靠。原料加工仍只在合理替代不足时作为备选。

按 [标准共创](co-design.md) 将主体特征与用户动作、互动效果及相关机构匹配，外观相似不证明机械适配。从原有方案验收选择，不另加固定审批阶段；保留“给我提供更多选项”。查资料和比较方案可以在绘图前进行，创建／生成项目几何仍须遵守图纸、路线、环境验收顺序。参数化执行按 [接入规则](parametric-structures.md)，所有来源最终回 Blender 整合与验收。

## 证据与版本怎样记

采用时在 [项目记录](project-record.md) 中引用卡号及来源 S，保留实际取得的源码、许可证、依赖版本、参数和输出对应关系。Git 固定提交指本次核查源码；除非原作者明确说明，不能认定历史实打使用同一提交。无固定版本的网页来源先记录项目编号与核查日期，取得文件后再记录文件名、下载日期与校验值；明确区分“文件已读取”和“作者明确提供设计源、尚未取回”，采用后者前补齐实际文件与许可核对，不把通用许可段中的格式列表当作文件存在证据；页面／文件无法复核时标为缺口，不继续称为已核实可复现方案。

分别记录作者成功打印、作者装配／动作记录、第三方复现、本项目实测，以及量化载荷／循环寿命结果。照片只能证明其可见的装配或状态；动画、渲染、下载量和软件测试不能替代物理记录。没有载荷或寿命数据就不宣称有。卡内的尺寸和切片条件用于重现作者案例，不自动成为当前项目默认值；未记录的材料、喷嘴、层高等保持未知。

在模型中标明 **核心保护区、外围适配区、运动／装入空间**。核心通常包括配合面、轴／孔、弹性梁、卡齿、间隙、止挡和连接根部。优先修改外围安装块和外观；不得为布尔、平滑、减面或缩放方便改变核心而仍沿用旧验证结论。按 Blender 原规则核对真实几何及保护区差异，不能仅凭操作范围声称核心未变。

## 由改动和缺口决定验证范围

每次采用或修改时只写一份简短计划：**原条件与证据 → 实际差异及其功能依赖 → 可沿用结论 → 本轮检查／必要试样 → 未知项**。按真实影响分类，不以“只是外观修改”作为免检理由。

| 本次情况 | 可以沿用什么 | 本轮应检查或试验什么 |
|---|---|---|
| 原机构核心、材料工艺及使用条件有适用证据且保持；仅改外围装饰 | 未受影响的配合、动作等已记录结论 | Blender 核对核心未变、运动／装入净空及外观；核对新增体量是否改变质量、重心、惯量或力臂。确无影响时不重复独立机构试样 |
| 改安装孔、外壳连接、包覆或夹持对象，核心暂未改 | 仍适用的原机构运动原理和原条件下的实物结果 | 检查根部、载荷传递、操作可达性与干涉；新接口或受力无依据时，仅做保留真实根部、安装与施力条件的局部试样。包覆会影响壳壁挤压／回弹时升级为核心变化 |
| 缩放或改变核心间隙、梁厚、齿形、预压、行程／止挡，或换材料、相关层向、喷嘴、层高、成形工艺、载荷／频率 | 只有与变化无关的结论 | 针对受影响的配合、回弹、定位、防脱、承力等安排原尺寸关键试样；实际依赖跨越整套机构时验证整套功能核心，不强行裁成失真的两个接头 |
| 源码与证据版本不匹配、关键原条件未知、动作要求改变或没有适配候选 | 已知来源与原理参考，不沿用未经覆盖的性能结论 | 明确缺口，优先补证据；不能补足时比较成熟替代、标准成品、简化需求或受控自行设计。决定配合物身份／尺寸的硬约束仍须先明确 |

材料／工艺缺项不是自动要求所有测试重做：先判断它影响哪项结论，再以最小有效试样补足。原设计的成功打印、静态照片或短时开合，不覆盖新增的长期夹持、承重或循环寿命要求。新设备条件若已有相同接口的适用校准／实测，可引用该证据；不能只因设备更新或标称更精准就跳过受影响的配合判断。

需要试样时复用 [机构试样子流程](modeling-plan.md)，不另设重复流程。先说明通过判据与返回节点，试样保留真实打印方向、材料、根部和必要载荷；打印授权与独立成果确认保持不变。高风险依赖未解决时不进入依赖它的大量精修，其他已获接受且无依赖的工作可以继续。

**停止条件：** 本轮差异对应的判据已满足，未变部分有适用证据，且关键未知项已有明确处理，就交付当前成果验收；不为“再保险”重复相同检查或打印。不通过时定位具体原因和受影响范围，没有新诊断或可检验的修改假设不连续重试。复用不豁免当前实际模型／导出、切片首层及风险区域检查，也不把旧切片或他人的打印完成状态当成本项目结果；切片仍按 [Bambu 流程](bambu.md) 的增量检查执行。

## 增补卡片的门槛

只把同时具备以下内容的具体设计加入有实物记录清单：可取得的设计源文件、明确允许相应用途与改编的许可、可追溯的作者／复现者物理记录、已知条件及缺口。设计源证据须为实际文件，或作者针对该设计明确提供可编辑源的说明；后者可登记候选卡，但必须标明尚未取回、采用前补核，不能标作已复现。仅通用许可中的格式举例、平台标签或第三方转述不满足此项。单个库的不同参数示例默认合并一张卡；平台总量、函数数量、原理动画和专利示意不计数。存在明确许可冲突、仅公开 STL 无设计源或物理证据不明的条目留在普通资料入口，不冒充同等证据的推荐。

卡片简写：编号／用途与动作；作者、源码版本与许可链接；物理证据与覆盖范围；原条件、件数及缺项；保护核心与可改范围；改造后重点验证。第三方代码和模型按各自许可使用，开放内容许可与软件许可分别写明；本包只保存链接和原创摘要，不捆绑素材或改标为 MIT。个人项目的实测留在项目记录，公开卡片不收录私人聊天或模型路径。
