# 用包内适配器配置和切片

进入 Bambu 阶段，有 3MF 时先用[包内适配器](bambu-adapter.md#在用户项目运行命令)实际 `inspect`。只有模型时从[工程准备](#2-工程与参数准备此阶段不切片)进入。用适配器处理它支持的每个步骤，依次准备参数、打开工程、切已确认的盘和核验产物。打印设置按[参数决策](slicing-parameters.md)，独立验收、真实预览和发送授权按 [Bambu 流程](bambu.md)。

## 1. 先核实本机能力与版本

核对实际软件版本、可执行文件、当前工程及预设版本，查 [官方 CLI 文档](https://github.com/bambulab/BambuStudio/wiki/Command-Line-Usage) 和适用版本的本机帮助／官方实现。查证配置加载、工程导出、摆盘、指定盘切片的真实语法与默认行为；文档或旧版成功记录不能证明本机新版可用。帮助无输出、程序退出码为零或软件已安装，都不能记为接口验证成功。

遇到未实测版本，先按本机帮助与该版本实现核对适配器所需参数。确认调用方式确有变化，才在工作副本适配受影响的调用或映射。不能安全改写工程时，只将相关字段交给 Bambu Studio 设置并另存，再核对盘号、材料、摆放和生效参数。

配置验收后，在已授权的目标盘上隔离试切，核对盘、对象、材料、配置差异和实际 G-code，再打开对应路径预览。记录已验证的软件版本和工程条件。如果命令缺少所需能力或修正后仍失败，按[单步回退与桌面授权](#单步回退与返回适配器)处理。

离线工程准备和离线切片只要求本地所需软件、模型及配置可用，不要求打印机在线、账户登录或已连接设备；若实际工具另有必需依赖，如实核实。发送物理打印单独核验连接、供料和本次授权。命令行切片能力不等于设备发送能力。

## 2. 工程与参数准备：此阶段不切片

优先从当前可编辑的未切片工程副本出发。打印方案获接受后，用适配器 `prepare` 修改已支持的字段。没有适用工程时，按本机已验证的方式导入模型并保存为 Bambu 工程，再 `inspect`。新增或调整打印盘等未支持操作按[单步回退](#单步回退与返回适配器)办理，保存后返回适配器核对。保留原工程，不猜测私有格式，不依赖作者个人模板。

按本轮清单读取模型身份／版本、对象及体积对应、数量、朝向、分盘和材料映射。以当前设备、耗材与工艺为基准，解析继承／默认值及工程、对象、局部覆盖，生成所选入口要求的完整配置；不能直接把包含继承关系的零散预设 JSON 当完整配置加载。核实全局命令行覆盖与对象／局部设置的实际作用，不用一份全局配置覆盖掉已确认的逐件差异。

| 内容 | 执行策略 |
|---|---|
| 普通参数 | 批量设置已核实的层高、壁数、填充、速度及自动支撑等字段，保留类型、单位、列表与比例语义，并按对象／盘／耗材区分范围 |
| 分盘、朝向、材料 | 仅更新已确认范围；保留用户已完成的摆盘，不默认调用自动摆放或自动定向；材料编号与实体槽位在发送前再核对 |
| 手涂支撑、局部绘制与特殊对象 | 优先保留已有工程数据；确需手动绘制时按[桌面授权](#单步回退与返回适配器)处理，不把面级标记当普通 JSON 开关 |
| 异常修复、弹窗和关键预览 | 使用 Bambu 界面及实际检查处理；程序化设置不能替代支撑可拆性、薄壁和活动间隙的视觉判断 |

若修改 3MF 内部数据，先核实对应版本的结构及字段，结构化解析、定位与校验，保留对象标识／引用、变换、分盘、材料、修改器和未修改的扩展数据。含中文的 XML 使用与实际字节一致的标准 UTF-8 声明，不写成 utf8；JSON 保留字段类型、列表及单位。优先只修改目标条目，网格和其他未修改条目保留原字节。公开源码中的格式实现是查证依据，不是永久稳定的编辑 API。

整体重新序列化能被通用解析器读取，不保证 Bambu 接受。若出现“无几何数据”等加载错误，先用未修改副本作对照，检查编码、格式和引用，不直接删件或重建模型。必要时采用“结构化解析定位与验证＋保留原格式的定向修改”；目标必须唯一、转义规则明确，修改后验证语义差异仅含计划字段。不得对整个压缩包盲目字符串替换；匹配不唯一、所需修改涉及且无法安全处理的未知扩展数据，或加载仍失败时，回到软件在副本中配置并另存，再回读验证。本机版本／格式首次适配时必须完成此回读；后续同版本、同字段与结构、覆盖处理方法及适用条件未变时复用已验证方法。首次涉及字段／特殊对象、软件忽略或重置设置、有未知差异时重新完整另存回读；普通稳定轮次仍核对实际载入和自动差异，不机械重复完整流程。

设置参数时同时维护软件实际需要的覆盖标记，不能只改数值却让载入时恢复系统预设。采用适配器已核实的工艺／各耗材槽／打印机字段分组，保留原标记并记录自动增补；无法可靠判断分组或标记结构时回到原生设置，不猜测或全量标记所有字段。已知失败、适用条件和已验证回退记录在用户项目内；同条件后续直接沿用可靠路径，不先重复触发一次已知失败。

减面、换网格或拓扑改变后，不能盲目复用依赖旧三角面编号的手涂支撑、接缝绘制等数据；只重建受影响的映射。确需前台操作时按[单步回退](#单步回退与返回适配器)处理。

在副本上准备新的未切片工程，保护原文件及用户未保存操作；需要续接未保存状态时先保存当前版本。变更配置或几何后，旧 G-code、切片预览和耗时统计都失效。优先从未切片工程构建；使用含旧切片数据的工程时，通过已核实方法使相关派生结果失效／移除并验证，不能留下会被误当成新结果的旧切片；不会安全处理时回到软件另存工程，不盲删未知 ZIP 成员。

输出参数差异表、输入与输出版本、实际修改范围及未验证项。重新读取结果核对字段及必要引用、对象数、尺寸／变换、材料和盘清单；纯配置修改不得悄悄改变几何或摆盘。代码与配置保存在用户项目内，不覆盖系统预设，不写入凭据。

## 3. 打开工程核验与配置验收

在 Bambu Studio 中作为工程／项目打开准备好的 3MF，按当前版本核对实际载入的设置和本轮摆盘，而不是只导入几何。只有 STL 或普通几何 3MF，不能宣称已交接完整打印设置。

用参数差异表及关键界面视图展示本轮结果，检查逐件设置、分盘、材料、警告与用户既有摆盘。文件能解压、参数已写入或代码成功，不代表软件接受并实际使用了这些设置；按前述触发条件决定完整另存回读；未触发时核对本轮实际载入和自动差异后继续当前验收。应用未支持、忽略或重置的字段先纠正，不伪称配置完成。

这一成果复用“摆盘与参数配置”验收节点：用户明确接受当前版本后才能切片。适配器的准备与切片分开调用；准备命令不携带切片／发送动作，不将完整流水线后台一口气跑完。

## 4. 配置验收后的程序化切片与预览

直接用适配器 [slice](bambu-adapter.md#对已选盘执行切片) 调用 Bambu Studio，绑定已接受工程的 SHA-256 与获准盘号。遇到新版本先按[本机能力验证](#1-先核实本机能力与版本)隔离试切。如果该入口改变已接受的盘或摆放且无法控制，记录证据，只为受影响的步骤选择可验证的替代入口。

以参数数组调用进程，正确处理空格与中文路径，不将未经转义的路径或设置拼成 shell 命令。采用当前项目内独立运行目录，保存输入版本／校验值、调用参数、进程状态、日志和实际输出；不把命令中的凭据写入记录。超时先检查进程及产物再决定重试，不启动重复切片任务；仍受阻时保留证据，按[单步回退](#单步回退与返回适配器)处理。

### 在工具内等待已有任务

当前步骤已获准时，只启动一次。短任务直接等待命令返回。长任务优先使用宿主提供的完成通知或有界等待；能在一次工具调用内续等同一进程、会话或远程任务时，按剩余时限续等，仅在完成、失败、需要用户选择或达到时限时返回状态。保留取消入口，发现需要授权的弹窗即交回。宿主必须交还控制时，保存已有句柄，下次从该任务继续。

Bambu 适配器的 slice 已在进程内等待切片。按作业规模设置有限的 --timeout；宿主等待时间较短时，可在工具层继续等待原命令。返回超时后先核对 run.json、PID 与已有产物，再决定是否恢复。完成后仍要检查输出、预览和交付；等待只覆盖当前已获准的任务。

### 4.1 核对实际输出与参数差异

结合退出码、工具提供的结构化结果／警告和本轮新输出检查，不将其中任何单一项当作成功证明。核对实际切片覆盖的盘、对象、材料、路径数据及文件完整性；旧文件或旧统计不能当作本轮输出。未提供结构化结果时按实际可得证据核验，不能虚构成功字段。

以已接受工程为基准，比较 GUI 另存工程（如有）与实际切片产物可取得的有效参数。适配器切片复用内置核验；其他入口产生 3MF 后按[适配器产物核对](bambu-adapter.md#处理切片差异)执行 `inspect`、`compare`。交叉检查全局和逐件覆盖、材料、温度及设备映射，以及 G-code 配置和实际路径。对象 ID 重排时按已核实的对象对应关系比较。可解释的非工艺元数据变化单独记录，未取得的字段标未验证。

出现未计划的参数改写时，先定位作用范围与实际影响；有依据的修正或显式覆盖须重新切片并再次比较。覆盖仍被改写时停止同条件重试，定位出错的是参数保存还是切片。仅该步按[单步回退](#单步回退与返回适配器)处理，后续受支持步骤继续用适配器，重新验证实际产物。若无法证明差异不影响本轮目标，或影响仍未知，保留“切片已生成、参数未验收”状态，不能进入发送。需要接受新参数时说明取舍并返回相应配置确认，不将意外改写当用户已接受。禁止只改切片包配置、G-code 注释或统计，使其看似符合目标而没有按目标重切。

在 02.09.01.70 的隔离实测中观察到 filament_prime_volume 被 CLI 归一化，显式同名覆盖也未保留输入值；这是需检测和回退的兼容性问题，尚无已验证的通用修复。不固定写入某个“正确值”，也不因单盘单色就断言无影响。

### 4.2 区分工程打开与已有路径预览

先判断导出物是可编辑工程、含模型与 G-code 的混合包，还是纯切片包。观察打开／进入预览时是否触发重切，确认界面读取的是本轮生成的路径；如果软件重新切片，将其登记为新的 GUI 结果，不能当作原 CLI 产物的预览证据。仅修改扩展名不等于转换文件类型。

优先使用当前版本已经验证的原生路径查看入口。多盘工程只切部分盘时，先核对包中保留盘和已有 G-code 的覆盖范围；仍含未切盘时，由助手按[已有路径预览](bambu-adapter.md#打开已有路径预览)核对本盘 G-code，并尝试原生查看入口。原生入口不能直接读取 CLI 包时，可依据同版本实际原生切片包结构，在独立副本中制作“仅供预览”的适配包；只转换已经核实的模型资源与引用结构，保留本轮各盘路径和必要元数据，不盲删未知 ZIP 条目。转换后检查引用、盘清单、CRC，并逐盘验证 G-code 字节或校验值与原产物完全一致，再在 GUI 实际打开核验。可编辑工程、CLI 原产物与查看副本分别保留并标明用途；查看副本不得作为正式发送包；发送时选用完成正式交接核验的 CLI 原产物，原产物不满足要求时才另行生成并验证正式产物。

02.09.01.70 实测中，保留几何的 CLI 导出包按项目打开会重切；按同版本纯切片结构制作的查看副本可直接预览。这只验证了该结构的查看适配，不是跨版本通用转换器；该次实测不支持 --gcodeviewer，当前使用环境仍须验证，不能照搬其他切片器的选项。缺少可验证的查看入口或适配方法时，按[单步回退](#单步回退与返回适配器)处理。确需生成新的 GUI 结果时，须有对应的前台接管同意和已验收的配置及盘号，再核对新结果。若仍无法完成，标明原 CLI 路径尚未预览。

打开对应新结果，按 [Bambu 切片检查](bambu.md#切片检查) 先看总览、各件真实首层与承托，再集中查看适用风险区；满足结束条件即展示真实时间／耗材及问题，等待切片结果验收。程序化切片不免除预览；没有界面或可用预览时只能报告已生成待检查结果，不能将其当作已验证可打印成果推进。

### 4.3 检查估算与辅助元数据

核对设备标识、材料、盘信息，以及时间和耗材的单位、范围与来源；负值、非有限值、明显超出总时长的首层时间、缺失关键设备字段均需定位。区分 G-code 路径、工程配置和辅助统计，不以辅助统计异常直接断言路径错误，也不据路径可显示判定发送资料完整。

02.09.01.70 实测中出现 slice_info 的 printer_model_id 为空、first_layer_time 明显异常。保留原始证据，优先交叉核对同轮 G-code、结构化结果和实际预览中一致的总估算；无法核实的字段标为未知，不猜值填补或复制旧统计。不把总估算可用写成异常元数据已经修复。缺失信息影响目标设备／材料匹配或正式交接时，通过当前软件重新生成并核验正式产物；仍无法核验则停止发送。

## 5. 降低交互成本与复用边界

正常轮次采用“复用基准 → 自动核对本轮差异 → 切片 → 集中预览 → 交付验收”；只在实际异常或条件变化时进入相应诊断。完整报告留在项目内；按[摘要定位明细](bambu-adapter.md#按摘要定位明细)读取工具状态、本轮必要值及所有未解释项。同次操作可复用与文件校验值绑定的解析结果，文件改变就失效，不用旧清单替代新输出核验。

### 单步回退与返回适配器

适配器支持的读写、比较、打开和切片一律直接调用。只为缺少能力或已有失败证据的那一步选替代入口。记录本轮文件、步骤、软件版本、限制或错误。优先选免占桌面的方法。以前用过 GUI、只查看 `--help` 或软件版本不同，都不足以跳过适配器。

Computer Use 会占用用户的前台桌面。凡需接管鼠标或键盘，包括导入、摆盘、弹窗、核验预览或回退切片，先说明具体步骤、受阻原因、预计占用时间及有无免占用替代，再等用户同意。已明确授权本轮该范围时直接沿用，结束即交还桌面。普通阶段确认不等于接管授权。适配器后台运行、`open` 仅启动程序及无需操控输入的只读检查无需接管授权。用户暂不授权时，继续可在后台完成的工作，注明仍待界面核验的项目。

同一软件版本、工程结构、相关设置和失败条件有匹配记录时，引用原证据，直接回退受影响步骤。条件变化只重验受影响能力。换网格、增件或重新分盘后，保存工作副本并回到 `inspect`。GUI 切片后同样回到适配器核对产物，再检查实际预览。适配器无法读取当前文件时，记录错误、替代核验范围和未验证项。

在[项目记录](project-record.md)保存模板、调用记录和适用范围。发送打印须另获授权。
